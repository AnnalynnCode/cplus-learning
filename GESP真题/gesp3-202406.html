答案：B

题目：下面流程图在yr输入2024时，可以判定yr代表闰年，并输出 2月是29天，则图中菱形框中应该填入（ ）。

A. (yr%400==0) || (yr%4==0)

单选题 · 整数范围
答案：C

题目：一般默认64位计算机系统中整型变量（int）还是32位，则整数能够表示的数据范围是（ ）。

A. -2³¹ ~ 2³¹
B. -2³¹-1 ~ 2³¹
C. -2³¹ ~ 2³¹-1 ✓
D. -2³¹-1 ~ 2³¹-1

📝 解题过程

  • 32位有符号整数（int），使用补码表示
  • 最高位是符号位，剩余31位表示数值
  • 正数最大：0后面31个1 = 2³¹ - 1 = 2147483647
  • 负数最小：1后面31个0（补码）= -2³¹ = -2147483648
  • 所以范围是 -2³¹ ~ 2³¹-1
通用公式 n位有符号整数（补码）范围：-2n-1 ~ 2n-1-1

答案：C

题目：下列代码将十进制转化成八进制，则横线上应填入（ ）。

void decimal2octal(int decimal) {
    int oct_number[100];

    }

A. oct_number[i] = decimal % 8; decimal /= 8;

单选题 · 异或交换
答案：C

题目：下列代码的输出结果是（ ）。

int a = 5;
int b = 10;
a = a ^ b;
b = a ^ b;
a = a ^ b;
cout << "a = " << a << ", b = " << b << endl;
A. a = 5, b = 10
B. a = 5, b = 5
C. a = 10, b = 5 ✓
D. a = 10, b = 10

📝 解题过程

  • 这段代码是经典的异或交换算法，不用临时变量交换两个数的值
  • 逐步推导（用二进制，a=5=0101, b=10=1010）：
① a = a ^ b  →  a = 0101 ^ 1010 = 1111 (15), b = 1010 (10)
② b = a ^ b  →  b = 1111 ^ 1010 = 0101 (5),  a = 1111 (15)
③ a = a ^ b  →  a = 1111 ^ 0101 = 1010 (10), b = 0101 (5)

最终：a=10, b=5，两个变量成功交换！

异或运算性质 ① 交换律：a^b = b^a   ② 结合律：(a^b)^c = a^(b^c)   ③ a^a = 0   ④ a^0 = a

单选题 · ASCII码
答案：C

题目：已知字符 '0' 的ASCII编码的十进制表示为48，则执行下面C++代码后，输出是（ ）。

string s = "0629";
int n = s.length();
int x = 0;
for(int i = 0; i < n; i++)
    x += s[i];
cout << x << endl;
A. 17
B. 158
C. 209 ✓
D. 316

📝 解题过程

  • 字符串 "0629" 有4个字符：'0', '6', '2', '9'
  • 程序中 x += s[i] 加的是字符的 ASCII码值，不是数字本身
  • '0' 的ASCII码 = 48，所以：
  • '0' = 48, '6' = 48+6 = 54, '2' = 48+2 = 50, '9' = 48+9 = 57
  • x = 48 + 54 + 50 + 57 = 209
关键区分 字符 '0'~'9' 的ASCII值从48开始递增。s[i] 取出的是字符，不是数字。要得到数字值，需要 s[i] - '0'。

答案：✓ 正确

📝 解析

例：5 - 3 = 5 + (-3的补码) = 0101 + 1101 = 1 0010（进位舍弃）= 0010 = 2 ✓

判断题 · 数组内存
答案：✗ 错误

题目：数组的所有元素在内存中可以不连续存放。

📝 解析

错误。C++中的数组在内存中是连续存放的，这是数组的基本特性。如果知道第一个元素的地址，就能计算出任意元素的地址：元素地址 = 首地址 + 索引 × 元素大小。正是因为连续存放，才能通过下标 O(1) 访问任意元素。

数组 = 一段连续的内存空间。这是数组区别于链表等数据结构的核心特征。

判断题 · 位运算条件
答案：✓ 正确

题目：如果 a 为 int 类型的变量，且表达式 ((a | 3) == 3) 的值为 true，则说明 a 在从0到3之间（可能为0、可能为3）。

📝 解题过程

  • 3的二进制：...0000 0011
  • a | 3 = 3 意味着：a和3按位或之后，结果恰好等于3
  • 这说明 a 在所有高于第1位的位上都必须是0
  • a 的第0位和第1位可以是0或1（因为3在这两位上已经是1，或任何值都不影响）
  • 所以 a 只能是：00(0), 01(1), 10(2), 11(3)
  • 如果 a 是负数，高位全为1，a|3 必然远远大于3
  • 因此 a 确实在 0~3 之间，表述正确
关键理解 a | 3 = 3 是判断 a 的值是否仅包含第0位和第1位的条件，等价于 a ∈ {0, 1, 2, 3}。
8
判断题 · 位运算陷阱
答案：✗ 错误

题目：执行下面C++代码后，输出的结果是8。

int a = 0b1010;
int b = 01100;
int c = a & b;
cout << c << endl;

📝 解题过程

  • a = 0b1010 = 二进制 1010 = 10（十进制）
  • b = 01100，以0开头表示这是八进制数字！
  • 01100（八进制）= 1×8³ + 1×8² + 0×8 + 0 = 512 + 64 = 576（十进制）
  • 10的二进制：0000 1010
  • 576的二进制：0010 0100 0000
  • a & b = 10 & 576 = 0，不是 8！
本题陷阱 0b1010 是二进制字面量，01100 是八进制字面量（以0开头）！两者进制不同，直接做位运算需要先统一到十进制。
9
判断题 · 随机数分析
答案：✓ 正确

题目：执行下面C++代码后，输出的结果不可能是89781。（ ）

#include <iostream>
#include <cstdlib>
#include <ctime>
using namespace std;
int main() {
    srand(time(NULL));
    int i = 1;
    int s[5];
    while(i <= 5) {
        int a = rand() % 10;
        if(a % 3 == (i + 1) % 3)
            s[i++] = a;
    }
    for(int i = 1; i <= 5; i++)
        cout << s[i];
    cout << endl;
    return 0;
}

📝 解题过程

  • 分析每次循环的约束条件 a % 3 == (i + 1) % 3：
  • i=1：a%3需要等于2，a只能是 2, 5, 8
  • i=2：a%3需要等于0，a只能是 0, 3, 6, 9
  • i=3：a%3需要等于1，a只能是 1, 4, 7
  • i=4：a%3需要等于2，a只能是 2, 5, 8
  • i=5：a%3需要等于0，a只能是 0, 3, 6, 9
  • 现在验证 89781：
  • s[1]=8 (8%3=2 ✓), s[2]=9 (9%3=0 ✓), s[3]=7 (7%3=1 ✓), s[4]=8 (8%3=2 ✓), s[5]=1
  • s[5]=1 需要满足 1%3==0，但 1%3=1 ≠ 0，不满足条件！
  • 所以 89781 确实不可能被输出
逐位约束法 这类题目需要对每个位置分析其取值范围，然后检查目标数字的每一位是否在对应范围内。

判断题 · 枚举算法
答案：✓ 正确

题目：把整数3025从中剪开分为30和25两个数，此时再将这两数之和平方，计算结果又等于原数。(30 + 25) × (30 + 25) = 55 × 55 = 3025，这样的数叫"雷劈数"。可以使用枚举的方法求出所有符合这样条件的四位数。（ ）

📝 解题过程

正确。可以用枚举法遍历所有四位数（1000~9999）：

  • 对每个四位数，将其拆分成前两位和后两位
  • 检查 (前两位 + 后两位)² 是否等于原数
  • 四位数的"雷劈数"包括：2025, 3025, 9801 三个
  • 验证：2025 → (20+25)²=45²=2025 ✓
  • 验证：3025 → (30+25)²=55²=3025 ✓
  • 验证：9801 → (98+01)²=99²=9801 ✓
枚举法 对于有限范围的问题（如四位数只有9000个），枚举法（逐一检查）是一种简单有效的策略。

编程题 · 移位加密
25分

题目：移位

题目描述：小杨学习了加密技术移位，所有大写字母都向后按照一个固定数目进行偏移。偏移过程会将字母表视作首尾相接的环，例如，当偏移量是3的时候，大写字母 A 会替换成 D，大写字母 Z 会替换成 C，总体来看，大写字母表 ABCDEFGHIJKLMNOPQRSTUVWXYZ 会被替换成 DEFGHIJKLMNOPQRSTUVWXYZABC。

注：当偏移量是26的倍数时，每个大写字母经过偏移后会恰好回到原来的位置。

输入格式：第一行包含一个正整数 n。

输出格式：输出在偏移量为 n 的情况下，大写字母表 ABCDEFGHIJKLMNOPQRSTUVWXYZ 移位替换后的结果。

样例1：

输入：3
输出：DEFGHIJKLMNOPQRSTUVWXYZABC

数据范围：保证 n 在合理范围内。

📝 详细解析

核心思路：这是经典的凯撒密码（Caesar Cipher）

  • 一共26个大写字母，编号 0~25（A=0, B=1, ..., Z=25）
  • 偏移 n 位后，原来位置 i 的字母会移动到位置 (i + n) % 26
  • 使用取模运算 % 实现字母表的循环（Z后面回到A）
  • 当 n 是26的倍数时，(i+n)%26 = i，字母回到原位

样例执行过程（n=3）：

原字母原位置 i新位置 (i+3)%26新字母
A03D
B14E
............
X230A
Y241B
Z252C

参考代码：

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < 26; i++) {
        int j = (i + n) % 26;    // 计算偏移后的位置
        char ch = 'A' + j;       // 转换为对应的大写字母
        cout << ch;
    }
    cout << "\n";
    return 0;
}
核心知识点 取模运算实现循环：(i + n) % 26 使得索引在 0~25 之间循环，实现字母表的首尾相接。这是处理环形结构的常用技巧。
P2
编程题 · 寻找倍数
25分

题目：寻找倍数

题目描述：小杨有一个包含 n 个正整数的序列 A，他想知道是否存在 i (1≤i≤n) 使得 Aᵢ 是序列 A 中所有数的倍数。

换句话说：是否存在某个数 Aᵢ，使得序列中的每一个数都能被 Aᵢ 整除（即 Aᵢ 是这些数的公约数，或者说所有数都是 Aᵢ 的倍数）。

等等，重新理解：Aᵢ 是序列中所有数的倍数，意思是 Aᵢ 是其他每个数的倍数，即 Aᵢ % Aⱼ == 0 对所有的 j 成立。换句话说，Aᵢ 是数组中的最大值，且是其他每个数的倍数。

输入格式：

  • 第一行包含一个正整数 t，代表测试用例组数
  • 接下来是 t 组测试用例。对于每组测试用例：
  • 第一行包含一个正整数 n
  • 第二行包含 n 个正整数，代表序列 A

输出格式：对于每组测试用例，如果存在满足条件的 i，输出 Yes，否则输出 No。

样例：

输入：
2
3
1 2 4
5
1 2 3 4 5

输出：
Yes
No

数据范围：保证数据在合理范围内。

📝 详细解析

核心思路：

  1. 如果存在某个数 Aᵢ 是所有数的倍数，那它一定是数组中的最大值（因为如果它不是最大的，那最大的数比它大，不能是它的约数）。
  2. 找到最大值 max_val 后，检查它是否能被每个数整除（即 max_val % Aⱼ == 0 对所有 j）。
  3. 如果每个数都能整除 max_val，输出 Yes；否则输出 No。

样例执行过程：

  • 序列1：[1, 2, 4]，最大值=4。4%1=0 ✓，4%2=0 ✓，4%4=0 ✓ → Yes
  • 序列2：[1, 2, 3, 4, 5]，最大值=5。5%3=2 ≠ 0 ✗ → No

参考代码：

#include <bits/stdc++.h>
using namespace std;

const int N = 1e5 + 10;
int a[N];

int main() {
    int t;
    cin >> t;
    while (t--) {
        int n;
        cin >> n;
        int x = 0;                   // 记录最大值
        for (int i = 1; i <= n; i++) {
            cin >> a[i];
            x = max(x, a[i]);         // 找最大值
        }
        int fl = 0;                    // 标记：是否有不满足条件的
        for (int i = 1; i <= n; i++) {
            if (x % a[i])              // 最大值不能被a[i]整除
                fl = 1;
        }
        if (fl)
            cout << "No\n";
        else
            cout << "Yes\n";
    }
    return 0;
}
核心知识点 最大值 + 整除检查：如果Aᵢ是所有数的倍数，它一定是最大值。找到最大值后，只需检查它能否被每个数整除。
