单选题 · 位运算优先级
答案：B

题目：执行以下程序段，输出值是（ ）

int x = 5;
if (x == 3 >> 2) x = 8 >> 3;
cout << x << endl;
A. 0
B. 5 ✓
C. 120
D. 1

📝 解题过程

>>（右移）优先级高于 ==，所以：

  • 3 >> 2 = 0（3除以4，整数=0）
  • 条件 x == 0 → 5 == 0 → false
  • if 语句体不执行，x 保持 5

输出：5

移位 ÷ 2ⁿ 右移n位 ≈ 除以2ⁿ（整数除法）。3>>2 = ⌊3/4⌋ = 0，8>>3 = ⌊8/8⌋ = 1。

单选题 · 数组交换
答案：A

题目：以下代码执行后，数组 arr 的内容是（ ）

int arr[6] = {1, 2, 3, 4, 5, 6};
for (int i = 0; i < 6; i += 2) {
    arr[i] = arr[i] + arr[i+1];
    arr[i+1] = arr[i] - arr[i+1];
    arr[i] = arr[i] - arr[i+1];
}
A. {2,1,4,3,6,5} ✓
B. {1,2,3,4,5,6}
C. {3,1,4,2,5,3}
D. {1,3,2,5,4,6}

📝 解题过程

这是经典的加减法交换两个数：

i=0 交换 arr[0]和arr[1]：

arr[0]=1+2=3 → arr[1]=3-2=1 → arr[0]=3-1=2 → {2,1,3,4,5,6}

i=2 交换 arr[2]和arr[3]：

arr[2]=3+4=7 → arr[3]=7-4=3 → arr[2]=7-3=4 → {2,1,4,3,5,6}

i=4 交换 arr[4]和arr[5]：

arr[4]=5+6=11 → arr[5]=11-6=5 → arr[4]=11-5=6 → {2,1,4,3,6,5}

不用临时变量交换 三句加减法实现 swap：① a=a+b; ② b=a-b; ③ a=a-b; 效果等同于交换两个变量的值。

单选题 · switch 分支
答案：B

题目：以下代码运行后，sum 的结果是（ ）

int arr[5] = {2, 4, 6, 8, 10};
int sum = 0;
for (int i = 0; i < 5; i++) {
    switch (arr[i] % (1|2)) {
        case 0: sum += 1; break;
        case 1: sum += 2; break;
        case 2: sum += 3; break;
    }
}
A. 10
B. 11 ✓
C. 14
D. 15

📝 解题过程

先算除数：1|2 = 1|2 = 001|010 = 011 = 3

所以 switch(arr[i] % 3)：

  • arr[0]=2, 2%3=2 → case 2: sum+=3 → sum=3
  • arr[1]=4, 4%3=1 → case 1: sum+=2 → sum=5
  • arr[2]=6, 6%3=0 → case 0: sum+=1 → sum=6
  • arr[3]=8, 8%3=2 → case 2: sum+=3 → sum=9
  • arr[4]=10,10%3=1 → case 1: sum+=2 → sum=11
技巧 1|2 需要先计算为3，switch 根据 arr[i]%3 的余数 0/1/2 分别加 1/2/3。

答案：✗ 错误

判断题 · 位运算优先级
答案：✗ 错误

题目：位运算符 & 、 | 、 ^ 、 ~ 的优先级高于算术运算符 + 、 - 、 * 、 / 。

📝 解析

错误。实际上：

  • ~（按位取反，一元运算符）优先级与 !、+（正号）同级，确实高于算术运算符
  • 但 &、|、^ 的优先级低于算术运算符

C++ 位运算优先级 算术 > 移位 > 关系 > & > ^ > |（只有 ~ 例外，与一元运算符同级最高）

判断题 · 补码计算技巧
答案：✓ 正确

题目：给定一个正整数 a，当需要计算 -a 的补码时，有这样一个计算技巧：将 a 的二进制形式从右往左扫描，遇到第一个 1 之后，将找到的第一个 1 左边的所有位都取反，能得到 -a 的补码。

📝 解析

正确！这确实是补码的一个巧妙计算技巧。

原理：-a 的补码 = ~a + 1。从右往左找第一个 1，这个 1 及其右边不变，左边全部取反，结果恰好等于 ~a + 1。

验证 a=6 (0110)：第一个1在位置1 → 右边"10"不变，左边"0"取反为"1" → 1010

-6 的4位补码 = 1010 ✓

口诀 找第一个1，左边全翻转——这是手算补码最快的方法。

判断题 · for 分号陷阱
答案：✗ 错误

题目：以下代码中，Hello 将被输出5次。

for (int i = 0; i < 5; i++);
{
    cout << "Hello" << endl;
}

📝 解析

错误！注意 for(...) 后面的分号！

这个分号是 for 循环的空语句体。循环体会执行5次空操作，循环结束后，下面花括号中的代码只执行一次。

所以 Hello 实际输出 1 次，不是 5 次。

常见陷阱 for/while 后面多加一个分号会导致循环体变空，后面的代码块只在循环结束后执行一次。这是初学者最容易犯的错误之一！

编程题 · 字符串处理 / 密码强度
25分

题目：密码强度

时间限制：1.0 s  |  内存限制：512.0 MB

题目描述：设计一个"密码强度检测器"。安全密码需满足三个条件：

  1. 密码至少包含8个字符
  2. 至少包含一个大写字母
  3. 至少包含一个数字

输入格式：第一行一个正整数 T 表示密码组数；接下来 T 行每行一个密码字符串（仅含大小写字母和数字）。

输出格式：对每组密码，满足要求输出 Y，否则输出 N。

输入样例：

6
PAs1s2an
1a2bCql3
Pa12bsna
ab1da3cd
Paabdbcd
Pa2

输出样例：

Y
Y
Y
N
N
N

📝 详细解析

解题思路：

  1. 遍历每个密码字符串
  2. 用布尔变量记录是否有大写字母、是否有数字
  3. 用 isupper(c) 检查大写，isdigit(c) 检查数字
  4. 最后检查：长度 ≥ 8 且 有大写字母 且 有数字

样例解释：

  • PAs1s2an → 8位 ✓、有大写(A,P) ✓、有数字(1,2) ✓ → Y
  • 1a2bCql3 → 8位 ✓、有大写(C) ✓、有数字(1,2,3) ✓ → Y
  • ab1da3cd → 8位 ✓、无大写 ✗ → N
  • Pa2 → 3位太短 ✗ → N

参考代码：

#include <iostream>
#include <string>
using namespace std;

int main() {
    int T;
    cin >> T;
    while (T--) {
        string password;
        cin >> password;

        bool has_upper = false;
        bool has_digit = false;

        for (size_t i = 0; i < password.length(); ++i) {
            if (isupper(password[i])) has_upper = true;
            if (isdigit(password[i])) has_digit = true;
        }

        if (password.length() >= 8 && has_upper && has_digit)
            cout << "Y\n";
        else
            cout << "N\n";
    }
    return 0;
}

题目：小杨的智慧购物

时间限制：1.0 s  |  内存限制：512.0 MB

题目描述：商店有 N 件文具，分为 M 种。每件文具有种类编号 K 和价格 P。小杨想买齐所有 M 种文具，每种只买最便宜的那一件。求总花费。

输入格式：第一行 M N；接下来 N 行每行 K P（种类编号和价格）。保证每种至少有一件。

输出格式：一行一个整数，总价。

输入样例：

2 5
1 1
1 2
1 1
2 3
2 10

输出样例：

4

📝 详细解析

解题思路：

  1. 创建数组 min_price[M+1]，初始化为极大值
  2. 遍历 N 件文具，对每种 K 更新最低价格：min_price[K] = min(min_price[K], P)
  3. 累加 min_price[1] + min_price[2] + ... + min_price[M]

样例推演：

  • 种类1：价格 1、2、1 → 最低价 1
  • 种类2：价格 3、10 → 最低价 3
  • 总价 = 1 + 3 = 4 ✓
思想 对每种文具只保留最便宜的 —— 这是经典的分组取最小值问题。

参考代码：

#include <iostream>
#include <cstring>
using namespace std;

int min_price[100005];

int main() {
    int M, N;
    cin >> M >> N;

    for (int i = 0; i <= M; i++)
        min_price[i] = 1000000000;  // 初始化为极大值

    for (int i = 0; i < N; ++i) {
        int K, P;
        cin >> K >> P;
        min_price[K] = min(min_price[K], P); // 更新最低价
    }

    int total_cost = 0;
    for (int k = 1; k <= M; ++k)
        total_cost += min_price[k];

    cout << total_cost;
    return 0;
}
时间复杂度 O(N + M)，只需遍历所有文具一次，再累加每种的最低价格即可。
