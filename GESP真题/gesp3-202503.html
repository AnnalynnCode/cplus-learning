单选题 · 进制与编码
答案：D

题目：Base64 编码将每3字节的输入数据编码为4字节的输出数据。如果输入数据长度不是3的倍数，会用 = 号填充。在Base64编码中，如果输入字符串的长度为10字节，编码后的字符串长度是多少？

A. 12 字节
B. 13 字节
C. 14 字节
D. 16 字节 ✓

📝 解题过程

  • Base64 的规则：每 3 字节 输入 → 4 字节 输出
  • 10 字节 ÷ 3 = 3 组……余 1 字节
  • 3 个完整组：3 × 4 = 12 字节
  • 剩下的 1 字节不足 3 字节，也需要编码成 4 字节（其中会用 = 填充）
  • 总共：12 + 4 = 16 字节
核心公式 编码后长度 = ⌈输入长度 ÷ 3⌉ × 4 = ⌈10 ÷ 3⌉ × 4 = 4 × 4 = 16 字节

单选题 · 字符编码
答案：B

题目：以下哪个字节序列是合法的 UTF-8 编码？

UTF-8 编码规则：
1字节：0xxxxxxx
2字节：110xxxxx 10xxxxxx
3字节：1110xxxx 10xxxxxx 10xxxxxx
4字节：11110xxx 10xxxxxx 10xxxxxx 10xxxxxx

A. 0xC0 0x80
B. 0xF0 0x90 0x80 0x80 ✓
C. 0x80 0x80 0x80
D. 0xFF 0xFE 0xFD

📝 解题过程

  • 选项 A：0xC0 0x80
    0xC0 = 1100 0000，以 110 开头表示2字节。但 11000000 中 xxxxx 全为0，这是"过长编码"(overlong)，不合法。
  • 选项 B：0xF0 0x90 0x80 0x80
    0xF0 = 1111 0000，以 11110 开头表示4字节 ✓
    0x90 = 1001 0000，以 10 开头 ✓
    0x80 = 1000 0000，以 10 开头 ✓
    0x80 = 1000 0000，以 10 开头 ✓
    全部合法！
  • 选项 C：0x80 0x80 0x80
    0x80 = 1000 0000，以 10 开头是"后续字节"，不能作为首字节。不合法。
  • 选项 D：0xFF 0xFE 0xFD
    0xFF = 1111 1111，不属于任何合法的 UTF-8 开头模式。不合法。
判断方法 逐字节检查：首字节的高位1的个数决定总字节数；后续字节必须以 10 开头。

单选题 · 进制转换
答案：A

题目：十进制数 111.111 的二进制表示可以是下面的哪一个？

A. 1101111.0001110001 ✓
B. 1101110.1001110001
C. 1101111.1001110001
D. 1101111.0011110001

📝 解题过程

  • 整数部分 111：
111 ÷ 2 = 55余 1↑
55 ÷ 2 = 27余 1↑
27 ÷ 2 = 13余 1↑
13 ÷ 2 = 6余 1↑
6 ÷ 2 = 3余 0↑
3 ÷ 2 = 1余 1↑
1 ÷ 2 = 0余 1↑

从下往上：111₁₀ = 1101111₂ ✓（前三个选项都满足）

  • 小数部分 0.111：
    0.111 × 2 = 0.222 → 取 0
    0.222 × 2 = 0.444 → 取 0
    0.444 × 2 = 0.888 → 取 0
    0.888 × 2 = 1.776 → 取 1
    0.776 × 2 = 1.552 → 取 1
    0.552 × 2 = 1.104 → 取 1
    0.104 × 2 = 0.208 → 取 0
    0.208 × 2 = 0.416 → 取 0
    0.416 × 2 = 0.832 → 取 0
    0.832 × 2 = 1.664 → 取 1
    小数部分 ≈ 0001110001₂

所以 111.111₁₀ ≈ 1101111.0001110001₂

小数转换口诀 乘2取整，顺向排列：小数部分不断 ×2，取出整数部分，直到为0或达到精度。

单选题 · 补码
答案：B

题目：在C++中，补码的主要作用是什么？

A. 提高浮点数的精度
B. 简化整数的加减法运算 ✓
C. 增加整数的表示范围
D. 优化内存分配

📝 解题过程

  • 补码最大的好处：加法和减法可以用同一套电路实现
  • 比如计算 5 - 3，在补码下就是 5 + (-3的补码)，直接用加法器完成
  • A 选项：浮点数精度与 IEEE 754 标准有关，与补码无关
  • C 选项：补码的表示范围并没有比原码大（8位补码：-128~127，原码：-127~127，范围相同）
  • D 选项：与内存分配无关
一句话总结 补码让计算机用同一个加法电路就能完成加法和减法，大大简化了硬件设计。

单选题 · 整数范围
答案：A

题目：在C++中，一个8位有符号整数（使用补码表示）的范围是？

A. -128 到 127 ✓
B. -127 到 128
C. -256 到 255
D. 0 到 255

📝 解题过程

  • 8位有符号整数（补码），最高位是符号位
  • 正数范围：0000 0000 到 0111 1111 = 0 到 127
  • 负数范围：1000 0000 到 1111 1111
  • 1000 0000（补码）= -128（这是补码的特殊值）
  • 1111 1111（补码）= -1
  • 所以范围是 -128 到 127
通用公式 n位有符号整数（补码）范围：-2n-1 到 2n-1 - 1
当n=8：-2⁷ 到 2⁷-1 = -128 到 127

单选题 · 双指针
答案：D

题目：以下代码的功能是将数组中的奇数和偶数分别放在数组的前半部分和后半部分，横线处应该填入的是？

#include <iostream>
using namespace std;

int main() {
    int arr[] = {1, 2, 3, 4, 5};
    int left = 0, right = 4;
    while (left < right) {
        while (arr[left] % 2 == 1 && left < right) left++;
        ————————————————————————————————————————————————————
        if (left < right) {
            swap(arr[left], arr[right]);
        }
        }
    for (int i = 0; i < 5; i++) {
        cout << arr[i] << " ";
    }
    return 0;
}
A. while (arr[left] % 2 == 0 && left < right) right--;
B. while (arr[right] % 2 == 0 && left < right) left--;
C. while (arr[right] % 2 != 0 && left < right) right--;
D. while (arr[right] % 2 == 0 && left < right) right--; ✓

📝 解题过程

  • 算法思路（双指针法）：
  • left 从左往右找偶数（应该放到右边去的）
  • right 从右往左找偶数（偶数已经位置对了，跳过）…… 等等不对！
  • 我们想要：奇数在左边，偶数在右边
  • 所以 left 找偶数（要移到右边的），right 找奇数（要移到左边的），找到后交换
  • 第一条 while：left 跳过奇数（奇数在左边是对的），找到偶数就停下
  • 第二条 while：right 应该跳过偶数（偶数在右边是对的），找到奇数停下
  • 所以：while (arr[right] % 2 == 0 && left < right) right--; ✓
执行过程 初始: {1,2,3,4,5}, left=0(1是奇数→右移), left=1(2是偶数→停), right=4(5是奇数→停), 交换2和5 → {1,5,3,4,2}, 继续…最终: {1,5,3,4,2}

题目：2025

题目描述：小A有一个整数 x，他想找到最小的正整数 k 使得下式成立：

(x & k) + (x | k) = 2025

其中 & 表示二进制按位与运算，| 表示二进制按位或运算。如果不存在满足条件的 k，则输出 -1。

输入样例：1025

输出样例：1000

数据范围：1 ≤ x ≤ 10⁹

📝 详细解析

核心数学原理：

对于任意两个整数 x 和 k，有一个重要恒等式：

(x & k) + (x | k) = x + k

为什么？按位来看：

  • 如果某一位上 x=0, k=0：x&k=0, x|k=0, 和为 0 = x+k(0)
  • 如果某一位上 x=0, k=1：x&k=0, x|k=1, 和为 1 = x+k(1)
  • 如果某一位上 x=1, k=0：x&k=0, x|k=1, 和为 1 = x+k(1)
  • 如果某一位上 x=1, k=1：x&k=1, x|k=1, 和为 2 = x+k(2) ✓

所以等式简化为：x + k = 2025

因此：k = 2025 - x

示例验证：

  • 输入 x = 1025
  • k = 2025 - 1025 = 1000
  • 验证：1025 & 1000 = ?
1025 = 100 0000 0001 (二进制)
1000 = 011 1110 1000 (二进制)
———————————————————————
  &  = 000 0000 0000 = 0
  |   = 111 1110 1001 = 2025
0 + 2025 = 2025 ✓

需要注意：k 必须是正整数。如果 x ≥ 2025，则 k ≤ 0，输出 -1。

参考代码：

#include <cstdio>
using namespace std;

int x;

int main() {
    scanf("%d", &x);
    for (int i = 1; i <= 2025; i++)
        if ((x & i) + (x | i) == 2025) {
            printf("%d\n", i);
            return 0;
        }
    printf("-1\n");
    return 0;
}
最优解法 直接计算 k = 2025 - x，检查 k > 0 即可。时间复杂度 O(1)。参考程序使用枚举法（O(2025)），也能通过。

题目：词频统计

题目描述：给定 n 个单词，找出其中出现次数最多的单词。忽略单词中字母的大小写（即 Apple、apple、APPLE 均视为同一个单词）。输入保证出现次数最多的单词只会有一个。

输入格式：

  • 第一行，一个整数 n，表示单词的个数
  • 接下来 n 行，每行包含一个单词（仅由大小写英文字母组成）

输出格式：输出出现次数最多的单词（小写形式）。

输入样例：

6
Apple
banana
apple
Orange
banana
apple

输出样例：apple

数据范围：1 ≤ n ≤ 100，每个单词长度 ≤ 30

📝 详细解析

解题思路：

  1. 读入所有单词，将每个单词统一转为小写
  2. 使用 map<string, int> 统计每个单词出现的次数
  3. 遍历 map，找到出现次数最多的单词并输出

样例执行过程：

输入转小写计数变化
Appleappleapple: 1
bananabananabanana: 1
appleappleapple: 2
Orangeorangeorange: 1
bananabananabanana: 2
appleappleapple: 3

最终：apple 出现 3 次（最多），banana 出现 2 次，orange 出现 1 次 → 输出 apple

参考代码：

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n; cin >> n;
    map<string, int> cnt;    // 统计每个单词的出现次数
    int mx = -1;               // 记录最大出现次数

    for (int i = 1; i <= n; i++) {
        string s; cin >> s;

        // 转为小写
        transform(s.begin(), s.end(), s.begin(), ::tolower);

        // 如果是新单词，先初始化为0
        if (!cnt.count(s))
            cnt[s] = 0;

        // 计数+1，并更新最大值
        mx = max(mx, ++cnt[s]);
    }

    // 输出出现次数最多的单词
    for (auto it = cnt.begin(); it != cnt.end(); it++)
        if (it->second == mx) {
            cout << it->first << '\n';
            break;  // 题目保证只有一个，找到就退出
        }

    return 0;
}
核心知识点 map 容器：自动按 key 排序的键值对  |  transform + tolower：将字符串转为小写  |  时间复杂度：O(n log n)
