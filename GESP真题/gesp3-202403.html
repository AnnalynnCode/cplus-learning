单选题 · 16位补码表示
答案：D

题目：整数 -5 的16位补码表示是（ ）

A. 1005
B. 1006
C. FFFA
D. FFFB ✓

📝 解题过程

求 -5 的16位补码，分三步走：

  • 第一步：+5 的16位原码
    5 = 0000 0000 0000 0101₂ = 0005₁₆
  • 第二步：求反码（按位取反）
    0005 → FFFA₁₆（每个十六进制位取反：0→F, 0→F, 0→F, 5→A）
  • 第三步：反码加1得补码
    FFFA + 1 = FFFB₁₆
补码公式 补码 = 反码 + 1。16位十六进制补码：正数5是0005，负数-5是FFFF-0005+1=FFFA+1=FFFB。

单选题 · 十六进制补码运算
答案：C

题目：如果16位短整数 -2 的二进制是"FFFE"，则短整数 -4 的十六进制是（ ）

A. FF04
B. FFFA
C. FFFC ✓
D. FFFH

📝 解题过程

已知 -2 的补码是 FFFE。在补码体系中，相邻负数的补码也是相邻的：

  • -2 = FFFE
  • -3 = FFFE - 1 = FFFD
  • -4 = FFFD - 1 = FFFC

验证：FFFC 按位取反得 0003，加1得 0004 = 4，所以 FFFC 确实是 -4 的补码。

补码规律 在补码中，-1=FFFF，-2=FFFE，-3=FFFD，-4=FFFC，以此类推。负数越小（越负），其补码的十六进制值也越小。

单选题 · 位运算按位或
答案：C

题目：下面C++代码执行后的输出是（ ）

1  int main()
2  {
3      cout << (3|16) << endl;
4      return 0;
5  }
A. 3
B. 16
C. 19 ✓
D. 48

📝 解题过程

| 是按位"或"运算，规则："有1出1，全0才0"。

将两个数写成二进制对齐：

   3 = 0001 0011
  16 = 0001 0000
 —————————————————
3|16 = 0001 0011 = 16 + 3 = 19

也可以直接看：16的二进制只有第5位是1（16=2⁴），3的二进制是 0011，所以 3|16 就是把3加上第5位，即 3+16=19。

按位或速记 任何数 | 2ⁿ = 原数 + 2ⁿ（如果原数该位为0的话）。3的二进制不影响16的位，所以3|16=3+16=19。

单选题 · 移位与相等比较
答案：B

题目：定义整数 int x = -5，则执行C++代码 cout << (x == (x<<1>>1)) 输出是（ ）

A. 0
B. 1 ✓
C. -5
D. 5

📝 解题过程

逐步分析：

  • x = -5
  • x << 1：左移1位，相当于乘以2。 -5 × 2 = -10
  • x << 1 >> 1：再右移1位。C++中对有符号负数右移通常采用算术右移（保持符号位不变），-10 >> 1 = -5
  • 所以 x == (x<<1>>1) → -5 == -5 → true
  • C++中 true 输出为 1
移位特性 C++中多数编译器对负数采用算术右移（补符号位），使得 x<<1>>1 = x。注意：若数值较大，左移可能溢出，高位丢失后右移无法恢复。

单选题 · ASCII码与字符累加
答案：C

题目：已知字符 '0' 的ASCII编码的十进制表示为48，则执行下面C++代码后，输出是（ ）

 1  int main()
 2  {
 3      string s = "316";
 4      int n = s.length();
 5      int x = 0;
 6      for(int i = 0; i < n; i++)
 7          x += s[i];
 8      cout << x << endl;
 9      return 0;
10  }
A. 10
B. 58
C. 154 ✓
D. 316

📝 解题过程

代码中 x += s[i] 累加的是字符的ASCII码值，不是数字本身！

  • 字符 '3' 的ASCII码 = 48 + 3 = 51
  • 字符 '1' 的ASCII码 = 48 + 1 = 49
  • 字符 '6' 的ASCII码 = 48 + 6 = 54
  • x = 51 + 49 + 54 = 154

如果要用字符得到对应的数字值，应该写 x += s[i] - '0'（此时结果是 3+1+6=10）。

易混淆点 字符参与算术运算时用的是ASCII码值（'0'=48, '1'=49, ...），不是看上去的"数字"。要得到数字值必须减去 '0'。

单选题 · 数组筛选逻辑
答案：C

题目：下面C++代码执行后数组中大于0的数的特征是（ ）

 1  int main()
 2  {
 3      int a[20], i;
 4      for(i = 0; i < 20; i++)
 5          a[i] = i + 1;
 6
 7      for(int i = 0; i < 20; i++)
 8          if((a[i] % 2) && (a[i] % 3))
 9              a[i] = 0;
10
11      for(i = 0; i < 20; i++)
12          if(a[i])
13              cout << a[i] << " ";
14      return 0;
15  }
A. 2的倍数
B. 3的倍数
C. 能被2或3整除的数 ✓
D. 能被2和3同时整除的数

📝 解题过程

关键是理解第8行的条件：if ((a[i]%2) && (a[i]%3))

  • a[i]%2 为真 → a[i] 不能被2整除
  • a[i]%3 为真 → a[i] 不能被3整除
  • 两个条件同时为真 → 既不能被2整除也不能被3整除 → 设为0（被"消灭"）
  • 剩下的非零数 = 能被2整除 或 能被3整除的数

逻辑口诀：满足条件则归零 → 剩下的就是"不满足条件"的数。不满足"既非2倍数也非3倍数" = "是2倍数或是3倍数"。

逻辑推理 德摩根律：!(非A且非B) = A或B。被清零的是"不能被2整除且不能被3整除"的数，留下的就是"能被2或3整除"的数。

单选题 · 数组逆序输出
答案：A

题目：执行下面C++代码后输出的第一个数是（ ）

 1  int main()
 2  {
 3      int a[20], i;
 4      for(i = 0; i < 20; i++)
 5          a[i] = i + 1;
 6
 7      for( ; i > 0; i--)
 8          cout << a[i-1] << " ";
 9      return 0;
10  }
A. 20 ✓
B. 19
C. 1
D. 不确定

📝 解题过程

  • 第一个循环：给 a[0]~a[19] 赋值为 1~20。循环结束后 i = 20

  • 之后依次输出 19, 18, 17, ..., 1（整个数组倒序输出）

所以输出的第一个数是 20。

循环技巧 注意第二个循环没有初始化语句（for( ; i>0; i--)），它复用了第一个循环结束后 i=20 的值，巧妙地实现了倒序输出。

单选题 · 大小写转换
答案：C

题目：在下列代码的横线处填写（ ），可以使得输出是 GESP IS INTERESTING

1  string str = "gEsP is Interesting";
2  int x = str.length();
3
4  for(int i = 0; i < x; i++)
5      if ((str[i] >= 'a') && (str[i] <= 'z'))
6          ________________________;
7  cout << str << endl;
A. str[i] += 'a' - 'A'
B. str[i] += 20
C. str[i] += 'A' - 'a' ✓
D. 无法实现

📝 解题过程

目标是：将小写字母转为大写字母。在ASCII表中：

  • 'A' = 65, 'a' = 97
  • 'A' - 'a' = 65 - 97 = -32
  • 小写字母 + (-32) = 小写字母 - 32 = 对应的大写字母

验证：'g' + ('A'-'a') = 103 + (-32) = 71 = 'G' ✓

A选项 'a'-'A'=32 会把小写变大（g→g+32=135，超出小写范围），B选项 +20 变成别的字符，都不对。

大小写转换公式 小写→大写：字符 - 32（即 += 'A'-'a'） |  大写→小写：字符 + 32（即 += 'a'-'A'）。小写字母ASCII码比大写大32。

单选题 · 单词计数逻辑
答案：C

题目：假设英文句子由若干词构成。下面C++代码统计输出的词数是（ ）

 1  string str = "gEsP is Interesting     !";
 2  int x = str.length();
 3  int nwords = 0;
 4
 5  for(int i = 0; i < x; i++)
 6      if (str[i] == ' ') {
 7          nwords++;
 8          while(str[++i] == ' ') ;
 9      }
10  cout << nwords << endl;
A. 1
B. 2
C. 3 ✓
D. 4

📝 解题过程

这段代码通过统计空格组的数量来计算单词数。字符串 "gEsP is Interesting !" 中的空格分布：

  • "gEsP is Interesting !"（3组空格）
  • 第1组：gEsP 后的 1 个空格 → nwords=1，while跳过后续空格
  • 第2组：is 后的 1 个空格 → nwords=2，while跳过后续空格
  • 第3组：Interesting 后的 5 个连续空格 → nwords=3，while一次性跳过全部5个空格

最终 nwords = 3。注意："!" 也算一个单词，但这个算法是以空格数来近似单词数，最后一个单词后没有空格，所以实际输出的是空格组数=3（单词数-1）。

字符串处理技巧 通过 while(str[++i]==' '); 跳过连续空格，确保多个连续空格只被计为一次分隔。++i先自增再判断，巧妙跳过当前已找到的空格。

答案：C

题目：C++的字符变量的码值是整数，下面字面量形式的字符码值最大的是（ ）

A. 100
B. 075
C. 0x70 ✓
D. 0x60

单选题 · 数组逆序条件统计
答案：D

题目：下面C++程序执行的结果是（ ）

 1  int main()
 2  {
 3      int a[20], i;
 4      int cnt = 0;
 5      for(i = 0; i < 20; i++)
 6          a[i] = i + 1;
 7
 8      for( ; i > 1; i--)
 9          if((a[i-1] + a[i-2]) % 3)
10              cnt++;
11      cout << cnt << endl;
12      return 0;
13  }
A. 5
B. 6
C. 10
D. 12 ✓

📝 解题过程

第一个循环后 i=20，a[0..19]=1..20。第二个循环从 i=20 到 i=2（共19次），每次检查相邻两数之和能否被3整除。

分析相邻和 %3 的规律：

i=20: (20+19)=39 %3=0  ← 不计数
i=19: (19+18)=37 %3=1  ← cnt=1
i=18: (18+17)=35 %3=2  ← cnt=2
i=17: (17+16)=33 %3=0  ← 不计数
...每3次中有2次计数（当余数≠0时）

19次迭代 ÷ 3 = 6组余2次。6 × 2 = 12 次。再加上 19−(6×3)=1 次余数，第19次（i=2：1+2=3%3=0）不计数。总计 12 次。

规律统计 相邻两数之和的余数呈周期规律：0,1,2,0,1,2...。19次中除去6个"余0"，剩下13个，但i=2对应(1+2)=3%3=0，再去掉1个，共12个非零。

单选题 · 位运算与算术运算比较
答案：B

题目：定义整型变量 int a=3, b=16，则 a|b 的值和 a+b 的关系是（ ）

A. 大于
B. 等于 ✓
C. 小于
D. 等于或小于

📝 解题过程

分别计算：

  • a | b = 3 | 16
    3=00011₂，16=10000₂，两数没有重叠的1位
    所以 3|16 = 00011 | 10000 = 10011₂ = 19
  • a + b = 3 + 16 = 19

19 = 19，所以 a|b 等于 a+b。

这是因为：当两个数在二进制中没有同时为1的位时，按位或等同于加法（因为没有进位）。

位运算和加法 当 a 和 b 的二进制位互不重叠（即 a&b=0）时，a|b = a+b。如果 a&b ≠ 0，则 a|b < a+b（因为有重叠的位不进位）。

判断题 · 反码与补码的关系
答案：✗ 错误

题目：任意整数 a 的二进制反码与补码都有1位不同。

📝 解题过程

  • 对于正数（包括0）：反码 = 补码 = 原码，完全相同，没有不同位
  • 对于负数：补码 = 反码 + 1，确实有差异（不只1位不同）
  • "任意整数"包括了正数，所以这个说法是错误的
编码规则 正数的原码、反码、补码三码合一，完全相同。只有负数才有反码和补码的转换。

判断题 · 移位运算符
答案：✗ 错误

题目：对整型变量 int a = 3，执行C++代码 a<<2 将把2输出到 a 中。

📝 解题过程

a << 2 是左移运算，表示 a 的二进制位向左移动2位，相当于 a × 2² = 3 × 4 = 12。

而且 a << 2 本身不会修改 a，它只是一个表达式。要改变 a 的值需要写成 a = a << 2;。

所以题中"将把2输出到a中"是错的。左移不是"输出数字2"，也不改变变量本身。

移位运算 a << n 不会改变 a 的值，而是返回移位后的结果。a << 2 = a × 4 = 12，不是2。

判断题 · 枚举法识别
答案：✓ 正确

题目：下面C++代码可以计算1到100的累加和，采用的是穷举法。

1  int i, sum = 0;
2  for(int i = 1; i <= 100; i++)
3      sum += i;
4  cout << sum << endl;

📝 解题过程

穷举法（枚举法）就是一一列举所有可能的方案，逐个检查或处理。

虽然这个问题也有数学公式（等差数列求和），但用循环逐个加的方法确实就是枚举法。

枚举法定义 枚举法（穷举法）= 把问题的所有可能情况一一列举出来进行处理。用 for 循环从 1 到 100 逐个累加就是一种枚举。

判断题 · 移位可逆性
答案：✗ 错误

题目：一个 int 类型变量 a，执行操作 (a<<2>>2) 后的值一定是 a。

📝 解题过程

这个说法是错误的。当 a 的数值较大，左移2位可能导致高位溢出丢失，再右移回来时，丢失的高位无法恢复。

例如：假设 int 是 8 位（方便理解），a = 64 = 01000000₂

  • a << 2：左移2位，高位01丢失 → 00000000₂ = 0
  • 再右移2位：0 >> 2 = 0
  • 0 ≠ 64，所以不是一定等于 a

只有当 a 较小、左移不会溢出时，结果才等于 a。

溢出问题 左移运算可能导致高位丢失（溢出），溢出的信息无法通过右移恢复。所以 (a<<n>>n)==a 只有在 a 较小、不溢出的前提下才成立。

判断题 · 八进制字面量移位
答案：✗ 错误

题目：在C++语言中，(010<<1) 执行结果是 100。

📝 解题过程

关键陷阱：010 是八进制数！

  • C++中，以 0 开头的数字是八进制字面量
  • 010₈ = 1×8 + 0 = 8（十进制）
  • 8 << 1 = 8 × 2 = 16
  • 16 ≠ 100，所以结果不是100

如果题目说的是100（八进制）= 64（十进制），也不是8<<1=16。总之结果不是100。

易混淆点 C++中以 0 开头的数字是八进制！010 ≠ 10，010 = 8。这是初学者最容易犯的错误之一。

判断题 · string.find()
答案：✓ 正确

题目：执行下面C++代码后将输出 2。

1  string str = "gEsP is Interesting";
2  int x = str.find("s");
3  cout << x << endl;

📝 解题过程

str.find("s") 返回第一个匹配字符的索引（从0开始）。

字符串 "gEsP is Interesting" 逐字符扫描：

  • 索引0: 'g'，不匹配
  • 索引1: 'E'，不匹配
  • 索引2: 's'，匹配！

判断题 · 数组找最小值
答案：✓ 正确

题目：对定义的数组 int a[7] = {2,0,2,4,3,1,6}，可以用简单循环就找到其中最小的整数。

📝 解题过程

可以用一个简单的循环遍历数组来找到最小值：

  • 设 min = a[0]，然后从 i=1 到 6，如果 a[i] < min，则更新 min = a[i]
  • 遍历完整个数组后，min 就是最小值

对于数组 {2,0,2,4,3,1,6}，遍历一遍就能找到最小值 0。

线性查找 找数组最小值只需 O(n) 的时间——用一个循环遍历一次即可。这是最基本也是最常用的数组操作之一。

判断题 · 循环等价转换
答案：✓ 正确

题目：任何一个 for 循环都可以转化为等价的 while 循环。

📝 解题过程

for 和 while 在功能上是等价的：

  • for(初始化; 条件; 迭代) { 循环体 }
  • 等价于：
    初始化; while(条件) { 循环体; 迭代; }

实际上，for 循环只是 while 循环的语法糖（更简洁的写法），两者在底层完全等价。任何一个 for 都可以改写为等价的 while，反过来也一样。

循环等价 for(init; cond; inc) { body } ≡ init; while(cond) { body; inc; }。两者底层逻辑完全相同，只是写法不同。

编程题 · 25分 · 字母求和
字符处理

📖 试题名称：字母求和

时间限制：1.0 s    内存限制：512.0 MB

题目描述

小杨同学发明了一种新型密码：

  • 每个小写字母代表一个正整数，即该字母在字母表中的位置（a=1, b=2, ..., z=26）
  • 每个大写字母代表一个负整数，即该字母 ASCII 码的相反数（A=-65, B=-66, ...）

对于给定的字符串，请你计算出它对应的加密前的整数是多少。例如 aAc 对应 1+(-65)+3 = -61。

输入格式

第一行一个正整数 n，表示字符串中字母的个数。
第二行一个由大写字母和小写字母组成的字符串 T，代表加密后得到的字符串。

输出格式

输出一行一个整数，代表加密前的整数。

样例

输入样例：

1  3
2  aAc

输出样例：

1  -61

📝 解题思路

  • 小写字母：值为 str[i] - 'a' + 1（a=1, b=2, ...）
  • 大写字母：值为 -(int)str[i]（ASCII码的相反数，A=-65, B=-66, ...）
  • 遍历累加：判断每个字符是大写还是小写，分别计算后累加到答案中
核心方法 区分大小写：if (str[i] >= 'a' && str[i] <= 'z') 是小写，else if (str[i] >= 'A' && str[i] <= 'Z') 是大写。

参考程序

 1  #include <iostream>
 2  #include <cstring>
 3  using namespace std;
 4  const int N = 100005;
 5  char str[N];
 6  int main() {
 7      int n;
 8      cin >> n;
 9      cin >> str;
10      int ans = 0;
11      for (int i = 0; i < n; i++) {
12          if (str[i] >= 'a' && str[i] <= 'z')
13               ans += str[i] - 'a' + 1;
14          else if (str[i] >= 'A' && str[i] <= 'Z')
15               ans -= str[i];
16      }
17      cout << ans << endl;
18      return 0;
19  }

编程题 · 25分 · 完全平方数
双重枚举

📖 试题名称：完全平方数

时间限制：1.0 s    内存限制：512.0 MB

题目描述

小杨同学有一个包含 n 个非负整数的序列 A，他想要知道其中有多少对下标组合 (i, j)（i < j），使得 A[i] + A[j] 是完全平方数。

如果 x 是完全平方数，则存在非负整数 k 使得 k² = x。

输入格式

第一行一个非负整数 n，表示非负整数个数。
第二行包含 n 个非负整数 A[1]...A[n]。

输出格式

输出一个非负整数，表示和是完全平方数的非负整数对数。

样例

输入样例：

1  5
2  1 4 3 3 5

输出样例：

1  3

样例解释：1+3=4=2²、1+3=4=2²（另一个3）、4+5=9=3²，共3对。

📝 解题思路

  • 双重循环枚举：用两重 for 循环枚举所有 (i, j) 组合（i < j）
  • 判断完全平方数：计算 m = A[i]+A[j]，求 sqrt(m)，判断平方后是否等于 m
  • 浮点误差处理：使用 sqrt(m + 1e-7) 避免浮点精度问题，或使用整数二分求平方根
判断完全平方数 int t = sqrt(m); if (t * t == m) → m 是完全平方数。添加小量 1e-7 可以避免 sqrt(25)=4.99999 被截断为4的问题。

参考程序

 1  #include <bits/stdc++.h>
 2  using namespace std;
 3  const int N = 1010;
 4  int a[N];
 5  int main() {
 6      int n;
 7      cin >> n;
 8      for(int i = 1; i <= n; i++)
 9          cin >> a[i];
10      int ans = 0;
11      for(int i = 1; i <= n; i++)
12          for(int j = i + 1; j <= n; j++) {
13              int m = a[i] + a[j];
14              int t = sqrt(m + 1e-7);
15              if(t * t == m)
16                  ans++;
17          }
18      cout << ans << "\n";
19  }
