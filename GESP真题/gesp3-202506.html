单选题 · 原码表示
答案：A

题目：8位二进制原码能表示的最小整数是：（ ）

A. -127 ✓
B. -128
C. -255
D. -256

📝 解题过程

  • 原码是用最高位表示符号（0正1负），其余位表示数值的编码方式
  • 8位二进制原码：最高位是符号位，剩下7位是数值位
  • 7位数值能表示的最大值 = 2⁷−1 = 127
  • 所以负数范围是 -127 ～ -0（原码中有"正0"和"负0"两个零）
  • 因此最小整数是 -127
关键区别 -128 是补码的最小值，不是原码的。原码因为有 ±0，负数范围只到 -127。

单选题 · 位运算技巧
答案：A

题目：以下哪个位运算可以交换两个变量的值（无需临时变量）( )

A. a = a ^ b; b = a ^ b; a = a ^ b; ✓
B. a = a & b; b = a | b; a = a & b;
C. a = a | b; b = a ^ b; a = a ^ b;
D. a = ~a; b = ~b; a = ~a;

📝 解题过程

这是经典的异或交换法，利用异或(^)的三个性质：

  • 自反性：a ^ a = 0
  • 恒等性：a ^ 0 = a
  • 交换律与结合律

假设 a=5, b=3，一步步推演：

① a = a ^ b  →  a = 5 ^ 3 = 6    (a=6, b=3)
② b = a ^ b  →  b = 6 ^ 3 = 5    (a=6, b=5)
③ a = a ^ b  →  a = 6 ^ 5 = 3    (a=3, b=5)

交换成功！

注意 如果 a 和 b 是同一个变量（地址相同），用异或交换会出错，结果变成0。

单选题 · 模拟过程
答案：B

题目：以下程序模拟了一个简单的小球反弹过程，横线处应该填入的是（ ）

int height = 10;
int distance = 0;
for (int i = 1; i <= 5; i++) {  // 模拟5次落地
    ——————————————————————
    height /= 2;           // 反弹后高度减半
    distance += height;     // 加上反弹路程
}
A. distance += height/2;
B. distance += height; ✓
C. distance += height*2;
D. distance += height+1;

📝 解题过程

分析循环每一步在做什么：

  1. 空白处 → 加上本次下落的高度
  2. height /= 2 → 高度减半（反弹后）
  3. distance += height → 加上反弹上升的路程

初始 height=10，第一次循环：distance += 10（下落）→ height变5 → distance += 5（反弹）

模拟思想 把每次"落地-反弹"拆成下落（空白处）和反弹（height/=2后加height）两部分，分开累加。

判断题 · 位运算
答案：✗ 错误

题目：x 是浮点数，(x >> 1) 等价于 x / 2

📝 解析

错误。C++中 >>（右移运算符）只能用于整数类型。如果 x 是 float 或 double，编译会直接报错，根本不会执行。

原因 浮点数采用 IEEE 754 格式存储（符号+指数+尾数），和整数的二进制结构完全不同，不能使用移位操作。

编程题 · 位运算 / 奇偶校验
25分

题目：奇偶校验

时间限制：1.0 s  |  内存限制：512.0 MB

题目描述：数据在传输过程中可能出错，接收方收到数据后通常会校验传输是否正确。给定 n 个非负整数，它们的校验码取决于这些整数在二进制下 1 的数量之和的奇偶性：如果有奇数个 1，校验码为 1；否则为 0。

输入格式：第一行一个正整数 n；第二行 n 个非负整数。

输出格式：一行两个整数：二进制下 1 的总数量，以及校验码（0或1）。

输入样例 1：

4
71 69 83 80

输出样例 1：

13 1

输入样例 2：

6
1 2 4 8 16 32

输出样例 2：

6 0

📝 详细解析

核心思路：逐个统计每个数二进制中1的个数，累加后取最低位得到校验码。

如何统计二进制中1的个数？使用 while (c) { v += c & 1; c >>= 1; } 逐位检查。

样例1验算：

  • 71 = 0b1000111 → 4个1
  • 69 = 0b1000101 → 3个1
  • 83 = 0b1010011 → 4个1
  • 80 = 0b1010000 → 2个1
  • 总数 4+3+4+2 = 13（奇数），校验码 = 13 & 1 = 1 ✓

样例2验算：1,2,4,8,16,32 都是2的幂，各含1个1 → 总数6个 → 校验码 = 6 & 1 = 0 ✓

参考代码：

#include <cstdio>
using namespace std;

int n, v;

int main() {
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) {
        int c;
        scanf("%d", &c);
        while (c) {
            v += c & 1;   // 检查最低位是否为1
            c >>= 1;        // 右移一位
        }
    }
    printf("%d %d\n", v, v & 1);
    return 0;
}
统计1的个数 while循环每次取最低位(c & 1)，累加后右移(c >>= 1)，直到c=0。时间复杂度 O(二进制位数)。
P2
编程题 · 贪心 / 分糖果
25分

题目：分糖果

时间限制：1.0 s  |  内存限制：512.0 MB

题目描述：有 n 位小朋友排成一队。第 i 位小朋友想要至少 ai 颗糖果，且分给他的糖果必须严格多于前一位。求最少需要准备多少颗糖果。

输入格式：第一行一个正整数 n；第二行 n 个正整数 ai。

输出格式：一行一个整数，表示最少准备的糖果数。

输入样例 1：

4
1 4 3 3

输出样例 1：

16

输入样例 2：

15
314 15926 53589793 238462643 383279502 8 8 4 1 9 7 1 6 9 3

输出样例 2：

4508143253

📝 详细解析

贪心策略：从左到右依次处理，每位小朋友实际得到的糖果 = max(自己的需求 a[i], 前一位得到的 + 1)

样例1推演：

  • 第1位：至少1颗 → 给 1 颗
  • 第2位：至少4颗 → max(4, 1+1) = 4 颗
  • 第3位：至少3颗 → max(3, 4+1) = 5 颗（必须比前一多！）
  • 第4位：至少3颗 → max(3, 5+1) = 6 颗

总和 = 1 + 4 + 5 + 6 = 16 ✓

注意事项 数据可能很大（样例2达到亿级），必须用 long long 存储答案，否则会溢出。

参考代码：

#include <cstdio>
#include <algorithm>
using namespace std;

const int N = 1005;

int n, a[N];
long long ans;

int main() {
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
        a[i] = max(a[i - 1] + 1, a[i]);  // 取两者较大值
        ans += a[i];                   // 累加
    }
    printf("%lld\n", ans);
    return 0;
}
时间复杂度 O(n)，只需一次遍历即可得到最优解。贪心策略正确性：局部最优 → 全局最优。
