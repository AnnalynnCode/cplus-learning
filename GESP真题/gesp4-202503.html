单选题 · 函数声明与定义
答案：A

题目：关于下述代码，说法错误的是（ ）。

int multiply(int x, int y);

int main() {
    int a = 4;
    int b = 5;
    int result = multiply(a, b);
    std::cout << "The result is: " << result << std::endl;
    return 0;
}

int multiply(int x, int y) {
    return x * y;
}
A. 函数 multiply 的定义应该放到函数 main 之前。 ✓
B. 函数声明 int multiply(int x, int y); 中明确指定了函数 multiply() 的返回值为整数类型。
C. 在 main 函数中，函数 multiply 通过 multiply(a, b) 被调用，其中 a 和 b 是定义在 main 函数中的变量，它们作为实参传递给了 multiply 函数的形参 x 和 y。
D. 运行上述代码，将输出 The result is: 20。

📝 解题过程

  • 关键概念：函数声明 vs 函数定义
  • 第1行 int multiply(int x, int y); 是函数声明（也叫函数原型），告诉编译器"存在这样一个函数"。
  • 第11-13行是函数定义（真正实现函数功能的代码）。
  • 有了函数声明在前，函数定义可以放在 main 之后，编译器在编译 main 时已经知道 multiply 的"样子"了。
  • A 是错误的：因为有函数声明，定义不需要放在 main 前面。
  • B 正确：声明中 int multiply(...) 明确了返回类型为 int。
  • C 正确：a 和 b 是实参，x 和 y 是形参。
  • D 正确：4 × 5 = 20，输出 The result is: 20。
核心知识点 函数声明（函数原型）让编译器预先知道函数的信息，定义可以放在调用之后。如果只有定义没有声明，且定义在调用之后，才会报错。

单选题 · 变量作用域
答案：B

题目：执行下述代码将输出（ ）。

int x = 10;
void func() { int x = 20; std::cout << x; }
int main() {
    func();
    std::cout << x;
    return 0;
}
A. 2020
B. 2010 ✓
C. 1010
D. 编译错误

📝 解题过程

  • 第1行：全局变量 x = 10，在整个程序中可见。
  • 第2行：func() 中定义了局部变量 x = 20，这个 x 屏蔽了全局变量 x。
  • 调用 func()：输出局部变量 x → 输出 20。
  • 回到 main：std::cout << x 中的 x 是全局变量 x → 输出 10。
  • 合起来：2010
局部优先原则 当局部变量和全局变量同名时，函数内部优先使用局部变量。这叫做"名称遮蔽"（Name Hiding）。

单选题 · 指针基础
答案：B

题目：执行下述代码后，变量 a 的值为（ ）。

int a = 10;
int* p = &a;
*p = 20;
A. 10
B. 20 ✓
C. 随机值
D. 编译错误

📝 解题过程

  • int* p = &a; → p 是一个指针，存储了变量 a 的内存地址。
  • *p = 20; → 解引用操作，意思是"通过 p 中存储的地址，找到那个变量，把它的值改成 20"。
  • 因为 p 指向 a，所以 *p = 20 等价于 a = 20。
  • 最终 a 的值变为 20。
指针三要素 &a 取地址 → 得到 a 的地址  |  int* p 声明指针  |  *p 解引用 → 访问指针指向的变量

单选题 · 参数传递
答案：D

题目：以下哪种参数传递方式可以避免拷贝大型对象？

A. 只能用值传递
B. 只能用引用传递
C. 只能用指针传递
D. 引用传递和指针传递均可 ✓

📝 解题过程

  • 值传递：会把整个对象复制一份给函数。如果对象很大（比如一个包含10000个元素的数组结构体），复制非常耗时。
  • 引用传递：只传递对象的"别名"，不复制对象本身。函数操作的就是原对象。
  • 指针传递：只传递对象的地址（通常4或8字节），也不复制对象本身。
  • 所以引用传递和指针传递都可以避免拷贝大型对象。
三种传递方式对比 值传递：复制整个对象（慢，但安全）
引用传递：传递别名（快，可修改原对象）
指针传递：传递地址（快，可修改原对象）

单选题 · 引用传递与值传递
答案：D

题目：执行下述代码，将输出（ ）。

void swap(int a, int &b) {
    int temp = a;
    a = b;
    b = temp;
}
int main() {
    int x = 1, y = 2;
    swap(x, y);
    std::cout << x << y;
    return 0;
}
A. 12
B. 21
C. 22
D. 11 ✓

📝 解题过程

  • 关键：参数 a 是值传递，参数 b 是引用传递（注意 int &b 中的 &）。
  • 调用 swap(x, y)：
    • a 获得了 x 的副本（a = 1），对 a 的修改不影响 x。
    • b 是 y 的引用，b 就是 y 的别名，修改 b 就是修改 y。
  • 执行过程：
    • temp = a → temp = 1
    • a = b → a = 2（但 x 不变！）
    • b = temp → b = 1 → y = 1（y 被修改了！）
  • 结果：x = 1（未变），y = 1（被改了），输出 11。
易混淆点 这个 swap 函数不能正确交换 x 和 y！因为 a 是值传递，对 a 的修改不会影响 x。只有 b 是引用传递，把 y 改成了 1。所以 x=1, y=1。

单选题 · 结构体初始化
答案：C

题目：下面的描述中，（ ）正确定义一个名为 Person 的结构体并正确初始化了一个 Person 结构体的变量 p。

A. Person p("Yang", 10); — 没有定义构造函数，不能这样初始化
B. string name, — 成员声明用了逗号，语法错误
C. Person p = { "Yang", 10 }; — 正确的聚合初始化 ✓
D. Person p = new Person("Yang", 10); — new 返回指针，类型不匹配

📝 解题过程

  • A 错误：结构体没有定义带参数的构造函数，不能使用 Person p("Yang", 10); 这种写法。
  • B 错误：成员声明用逗号分隔是错误的，应该用分号：string name, int age; 不对，应该是 string name; int age;。而且 C++ 中 struct 成员默认 public，但逗号语法仍不正确。
  • C 正确：这是聚合初始化（aggregate initialization），用花括号按顺序给成员赋值：name = "Yang", age = 10。
  • D 错误：new 返回的是指针（Person*），不能赋值给 Person 类型的变量 p。
结构体初始化方式 聚合初始化：Person p = {"Yang", 10}; 或 Person p{"Yang", 10};
逐成员赋值：Person p; p.name = "Yang"; p.age = 10;

单选题 · 结构体嵌套
答案：D

题目：给定如下代码，下面描述错误的是（ ）。

struct Person {
    std::string name;
    int age;
    struct Address {
        std::string street;
        std::string city;
    };
    Address address;
};
A. 结构 Person 内嵌套结构 Address
B. Person 有一个 Address 类型的 address 成员
C. 一个 Person 类型的变量 p 的 address 的初始化可以写成：p.address.street = "123 Main St"; p.address.city = "Anytown";
D. 结构的嵌套可以减少命名冲突，因此可以不必控制嵌套层次 ✓

📝 解题过程

  • A 正确：结构 Person 内部定义了结构 Address，这就是嵌套结构。
  • B 正确：成员 Address address; 使用了嵌套定义的 Address 类型。
  • C 正确：通过 . 运算符逐层访问：p.address.street。
  • D 错误：虽然嵌套确实可以减少命名冲突（Address 在 Person 内部，不会和外面的 Address 冲突），但不能无限制嵌套。过度嵌套会使代码难以理解和维护，应该合理控制层次。
嵌套结构的原则 嵌套结构可以表达"从属关系"，但过度嵌套会让代码变得复杂。一般嵌套1-2层比较合适，不宜超过3层。

单选题 · 递推算法/爬楼梯
答案：B

题目：小杨正在爬楼梯，需要爬 n 阶才能到达楼顶。如果每次可以爬 1 个或 2 个台阶，下面代码采用递推算法来计算一共有多少种不同的方法可以爬到楼顶，则横线上应填写（ ）。

int f(int n) {
    if (n == 1 || n == 2)
        return n;

    int f1 = 1;
    int f2 = 2;
    int res = 0;
    for (int i = 3; i <= n; i++) {
        ________________________________   // 在此处填入代码
    }
    return res;
}
A. res += f1 + f2; f1 = f2; f2 = res;
B. res = f1 + f2; f1 = f2; f2 = res; ✓
C. res += f1 + f2; f2 = res; f1 = f2;
D. res = f1 + f2; f2 = res; f1 = f2;

📝 解题过程

  • 这是经典的爬楼梯问题，递推公式：f(n) = f(n-1) + f(n-2)
  • 因为到达第 n 阶的方法 = 从 n-1 走1步上来 + 从 n-2 走2步上来。
  • 变量含义：f1 = f(i-2), f2 = f(i-1), res = f(i)
  • 每轮循环需要：
    • res = f1 + f2（当前 = 前两个之和），注意是 = 不是 +=
    • f1 = f2（f1 移动到 f2 的位置）
    • f2 = res（f2 移动到新计算出的 res 的位置）
  • A 用 res +=，会让结果累加，错了。
  • C 和 D 的更新顺序不对（先更新 f2 再更新 f1 会导致 f1 获得错误的值）。
递推过程示例 (n=5) f1=1, f2=2
i=3: res=1+2=3, f1=2, f2=3
i=4: res=2+3=5, f1=3, f2=5
i=5: res=3+5=8, f1=5, f2=8 → 返回 8

单选题 · 时间复杂度
答案：B

题目：给定如下算法，其时间复杂度为（ ）。

bool f(int arr[], int n, int target) {
    for (int i = 0; i < (1 << n); i++) {
        int sum = 0;
        for (int j = 0; j < n; j++) {
            if (i & (1 << j)) {
                sum += arr[j];
            }
        }
        if (sum == target) return true;
    }
    return false;
}
A. O(n)
B. O(n × 2ⁿ) ✓
C. O(n²)
D. O(2ⁿ)

📝 解题过程

  • 外层循环：for (int i = 0; i < (1 << n); i++)
  • 1 << n = 2ⁿ，所以外层循环执行 2ⁿ 次。
  • 内层循环：for (int j = 0; j < n; j++) → 执行 n 次。
  • 总执行次数 ≈ 2ⁿ × n = n × 2ⁿ
  • 时间复杂度为 O(n × 2ⁿ)。
  • 这个算法其实是用枚举子集的方式（通过位运算 i 的每一位来表示是否选 arr[j]），来查找是否有一个子集的和等于 target。
时间复杂度计算 外层 × 内层 = 2ⁿ × n。注意 O(2ⁿ) 和 O(n×2ⁿ) 是不同的，这里内层不是常数，所以是 n×2ⁿ。

单选题 · 排序稳定性
答案：B

题目：下面关于排序稳定性的描述，正确的是（ ）。

A. 稳定性指算法的时间复杂度恒定
B. 稳定排序保证相同元素的相对顺序不变 ✓
C. 选择排序是稳定排序
D. 插入排序不是稳定排序

📝 解题过程

  • A 错误：稳定性和时间复杂度是两个不同的概念。时间复杂度指运行时间随数据量的增长速度。
  • B 正确：稳定排序的定义就是：如果两个元素的值相等，排序后它们的先后顺序保持不变。
  • C 错误：选择排序不是稳定排序。例如 [5, 5, 2]，第一轮会把第一个5和2交换，两个5的相对顺序就变了。
  • D 错误：插入排序是稳定排序。插入时遇到相等的元素会放在后面，保持原有顺序。
常见排序稳定性速记 稳定：冒泡、插入、归并  |  不稳定：选择、快速、堆排序

单选题 · 冒泡排序
答案：A

题目：对数组 arr[]={5, 3, 8, 1} 进行升序排序，执行第一轮冒泡排序后数组 arr 中的内容为（ ）。

A. 3, 5, 1, 8 ✓
B. 3, 1, 5, 8
C. 3, 5, 8, 1
D. 5, 3, 8, 1

📝 解题过程

  • 冒泡排序第一轮：从前往后两两比较，把最大的数"冒"到最后。
  • 初始：[5, 3, 8, 1]
  • 比较 5 和 3：5>3，交换 → [3, 5, 8, 1]
  • 比较 5 和 8：5<8，不交换 → [3, 5, 8, 1]
  • 比较 8 和 1：8>1，交换 → [3, 5, 1, 8]
  • 第一轮结束，最大值 8 已到达最后位置。
  • 结果：{3, 5, 1, 8}
冒泡排序口诀 每轮把当前未排序部分的最大值像气泡一样"浮"到最后面。第1轮确定最后一个，第2轮确定倒数第二个……

单选题 · 异常处理
答案：A

题目：运行下面的代码，将出现（ ）。

double hmean(double a, double b) {
    if (a == -b)
        throw runtime_error("Runtime error occurred.");
    return 2.0*a*b/(a + b);
}

int main() {
    double x = 10;
    double y = -10;

    try {
        int result = hmean(x, y);
        cout << "hmean: " << result << endl;
    }
    catch (const runtime_error& e) {
        cout << "Caught: " << e.what() << endl;
    } catch (...) {
        cout << "Caught an unknown exception." << endl;
    }
    return 0;
}
A. 屏幕上输出 Caught: Runtime error occurred. ✓
B. 屏幕上输出 Caught an unknown exception.
C. 程序调用 std::terminate()
D. 编译错误

📝 解题过程

  • x = 10, y = -10，满足 a == -b（即 10 == -(-10) = 10）。
  • 所以 hmean 函数会 throw 一个 runtime_error 异常。
  • main 中用 try-catch 捕获异常：
    • 第一个 catch 匹配 const runtime_error&，成功捕获。
    • 输出 "Caught: " + 异常信息。
  • 注意 int result = hmean(x, y); 中，虽然 hmean 返回 double，但这里用 int 接收——这只是一个隐式类型转换，不影响异常处理。
  • 另外 拼写错误：代码中写的是 runtime_error（少了个 e），但题目选项中给出的就是原样，这说明这不是考察重点（或者代码能通过编译，runtime_error 的拼写取决于具体命名空间）。
异常处理流程 throw 抛出异常 → try 块中代码停止执行 → 跳到匹配的 catch 块 → 处理完后继续执行 catch 后面的代码。

单选题 · 输出重定向
答案：C

题目：下面哪种方式不能实现将字符串 "Happy Spring!" 输出重定向到文件 log.txt（ ）。

A. freopen + cout
B. ofstream 直接写入
C. ofstream 创建了但用 cout 输出 ✓
D. rdbuf 重定向 cout 缓冲区

📝 解题过程

  • A 可以：freopen("log.txt", "w", stdout); 把标准输出重定向到文件，之后 cout 就输出到文件了。
  • B 可以：ofstream outFile("log.txt"); outFile << ...; 直接用文件输出流写入。

  • D 可以：cout.rdbuf(log_file.rdbuf()); 把 cout 的底层缓冲区替换为文件的缓冲区，之后 cout 就输出到文件了。
输出重定向三种方法 ① freopen 重定向 stdout  |  ② 直接用 ofstream  |  ③ rdbuf() 替换 cout 的缓冲区

判断题 · 函数返回类型
答案：✗ 错误

📝 解析

C vs C++ C语言允许省略（默认int），C++不允许省略返回类型。这是C++比C更严格的地方之一。

判断题 · 指针运算
答案：✗ 错误

题目：假设整数数组 arr[4]= {0, 1, 2, 3}; 的第一个元素在内存中的地址为 0x7ffee4065820，经过 int* p = arr; p += 1; 后，指针 p 的值是1。

📝 解析

错误。指针的加法不是加数值，而是加类型大小。p += 1 会使 p 指向下一个 int 元素。因为 int 占 4 字节，p 的值会变为 0x7ffee4065824（地址值 + 4），而不是 1。

指针算术 p + n = p 的地址值 + n × sizeof(元素类型)。int* 加1，地址值加4；char* 加1，地址值加1。
5
判断题 · 二维数组参数
答案：✗ 错误

题目：二维数组作为函数参数时，必须显式指定所有维度的大小。

📝 解析

错误。二维数组作为函数参数时，第一维的大小可以省略，但第二维（及以后各维）必须指定。例如 void func(int arr[][4]) 是合法的（省略了行数），而 void func(int arr[][]) 是不合法的。

记住口诀 多维数组作参数：只有第一维可以省略，其余维度必须写明。
6
判断题 · 递推概念
答案：✓ 正确

题目：递推是一种通过已知的初始值和递推公式，逐步求解目标值的算法。

📝 解析

正确。这是递推（iteration/递推法）的准确定义。例如斐波那契数列：已知 f(1)=1, f(2)=1，递推公式 f(n)=f(n-1)+f(n-2)，就可以逐步算出任意 f(n)。递推的核心是从已知出发，一步一步推导出未知。

7
判断题 · 冒泡排序复杂度
答案：✓ 正确

题目：考虑最坏情况下冒泡排序算法的时间复杂度，n 为待排序数字的数目，则其递推关系式为 T(n) = T(n-1) + n，T(1) = 0。

📝 解析

正确。冒泡排序最坏情况（完全逆序）：第1轮比较 n-1 次，第2轮比较 n-2 次……总共比较 (n-1)+(n-2)+…+1 = n(n-1)/2 次，时间复杂度O(n²)。递推关系 T(n) = T(n-1) + n 展开后正是这个和式。

8
判断题 · 插入排序最好情况
答案：✓ 正确

题目：插入排序在最好情况（已有序）下的时间复杂度是 O(n)。

📝 解析

正确。当数组已经有序时，插入排序每次只需要比较一次就能确定位置，不需要移动元素。总共 n-1 次比较，时间复杂度为 O(n)。这也是插入排序相比选择排序的一个优势。

9
判断题 · 选择排序
答案：✓ 正确

题目：对数组 arr[]={4, 3, 1, 5, 2} 进行升序排序，执行第一轮选择排序后数组 arr 中的内容是 {1, 4, 3, 5, 2}。

📝 解析

正确。选择排序第一轮：遍历整个数组找到最小值（1，在索引2），将它与第一个元素（4，索引0）交换位置。交换后：{1, 3, 4, 5, 2} → {1, 4, 3, 5, 2}（等一下，换回来：把索引2的1和索引0的4交换，4到了索引2的位置）。结果确实是 {1, 4, 3, 5, 2}。

10
判断题 · 未捕获异常
答案：✓ 正确

题目：未捕获异常会调用 std::terminate 终止程序。

📝 解析

正确。在 C++ 中，如果异常被抛出（throw）但没有被任何 catch 捕获，程序会调用 std::terminate() 来终止运行。默认情况下，terminate() 会调用 abort()，导致程序异常退出。

编程题 · 二维网格
25分

题目：荒地开垦

题目描述：小杨有一大片荒地，可以表示为一个 n 行 m 列的网格图。小杨想要开垦这块荒地，但荒地中一些位置存在杂物，对于一块不存在杂物的荒地，该荒地可以开垦当且仅当其上下左右四个方向相邻的格子均不存在杂物。小杨可以选择至多一个位置，清除该位置的杂物，移除杂物后该位置变为荒地。小杨想知道在清除至多一个位置的杂物的情况下，最多能够开垦多少块荒地。

输入格式：

  • 第一行包含两个正整数 n, m。
  • 之后 n 行，每行包含一个长度为 m 且仅包含字符 . 和 # 的字符串。如果为 .，代表该位置为荒地，如果为 #，代表该位置为杂物。

输出格式：输出一个整数，代表在清除至多一个位置的杂物的情况下，最多能够开垦的荒地块数。

输入样例：

3 5
.....
.#..#
.....

输出样例：11

📝 详细解析

核心思路：

  1. 判定可开垦条件：一块荒地（.）可以开垦，当且仅当它的上下左右四个邻居都不是杂物（#）。
  2. 允许清除一个杂物：我们可以选择一个杂物格子清除（变成.），这可能会让原来不能开垦的相邻荒地变得可以开垦。
  3. 算法步骤：
    • 先统计不需要清除就能开垦的荒地数量（ans）。
    • 对于每个荒地格子，统计它周围有几个杂物：如果周围有恰好1个杂物，说明清除那个杂物后该荒地就能开垦了，给那个杂物位置 +1 贡献。
    • 对于每个杂物格子，如果它周围没有杂物（全是荒地），清除它自身后自己也能变成可开垦的荒地，给自己 +1。
    • 最后取所有位置贡献值的最大值 mx，答案 = ans + mx。

样例执行过程：

原始网格：
.....
.#..#
.....

移除第二行第二个 #（即 (2,2) 位置）后：

.....
....#
.....

第一行5块 + 第二行前4块 + 第三行前2块（等等，实际计算需要遍历每个格子检查四邻）。清除 (2,2) 的杂物后，原本被这个杂物"挡住"的荒地都变得可以开垦了，总共 11 块。

时间复杂度：O(n×m)，需要遍历每个格子和它的4个邻居。

参考代码：

#include <bits/stdc++.h>
using namespace std;
const int N = 1005;
char mat[N][N];
int a[N][N];
const int d[4][2] = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};
int main() {
    int n, m, ans = 0;
    scanf("%d%d", &n, &m);
    for (int i = 1; i <= n; i++)
        scanf("%s", mat[i] + 1);
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++) {
            int num = 0, p = -1;
            for (int k = 0; k < 4; k++)
                if (mat[i + d[k][0]][j + d[k][1]] == '#')
                    num++, p = k;
            if (mat[i][j] == '.' && num == 1)
                a[i + d[p][0]][j + d[p][1]]++;
            else if (mat[i][j] == '.' && num == 0)
                ans++;
            else if (mat[i][j] == '#' && num == 0)
                a[i][j]++;
        }
    int mx = 0;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            mx = max(mx, a[i][j]);
    cout << ans + mx << endl;
    return 0;
}
核心知识点 方向数组 d[4][2] 枚举四个方向  |  贡献统计 a[N][N] 记录清除每个杂物能获得的收益  |  边界处理 mat 数组从1开始，外围自动为0

题目：二阶矩阵

题目描述：小 A 有一个 n 行 m 列的矩阵 A。小 A 认为一个 2×2 的矩阵 B 是好的，当且仅当 B[0][0] × B[1][1] == B[0][1] × B[1][0]。小 A 想知道 A 中有多少个好的子矩阵。

输入格式：

  • 第一行，两个正整数 n, m。
  • 接下来 n 行，每行 m 个整数。

输出格式：一行，一个整数，表示 A 中好的子矩阵的数量。

输入样例：

3 4
1 2 1 0
2 4 2 1
0 3 3 0

输出样例：2

📝 详细解析

核心思路：

  1. 子矩阵大小固定为 2×2（题目名称"二阶矩阵"就暗示了这一点）。
  2. 好矩阵的条件：左上 × 右下 == 右上 × 左下（即对角线的乘积相等）。
  3. 遍历所有可能的 2×2 子矩阵：对于每个 (i, j) 作为左上角，检查以它为起点的 2×2 子矩阵。
  4. 共有 (n-1) × (m-1) 个 2×2 子矩阵需要检查。

样例执行过程：

矩阵：
1 2 1 0
2 4 2 1
0 3 3 0

检查所有 2×2 子矩阵：
(0,0): 1×4=4, 2×2=4 → 4==4 ✓ 好的!
(0,1): 2×2=4, 1×4=4 → 4==4 ✓ 好的!
(0,2): 1×1=1, 0×2=0 → 1!=0 ✗
(1,0): 2×3=6, 0×4=0 → 6!=0 ✗
(1,1): 4×3=12, 2×3=6 → 12!=6 ✗
(1,2): 2×0=0, 1×3=3 → 0!=3 ✗

总共 2 个好的子矩阵 → 输出 2

时间复杂度：O(n×m)，只需遍历每个可能的左上角，常数时间检查。

参考代码：

#include <bits/stdc++.h>
using namespace std;

const int N = 505;
int n, m;
int a[N][N];
int ans;

int main() {
    scanf("%d%d", &n, &m);
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            scanf("%d", &a[i][j]);
    for (int i = 1; i < n; i++)
        for (int j = 1; j < m; j++)
            if (a[i][j] * a[i + 1][j + 1] == a[i + 1][j] * a[i][j + 1])
                ans++;
    printf("%d\n", ans);
    return 0;
}
核心知识点 二维数组遍历：枚举所有 2×2 子矩阵的左上角  |  条件判断：对角乘积相等  |  注意：循环边界是 i < n 和 j < m，因为需要 i+1 和 j+1
