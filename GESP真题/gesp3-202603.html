单选题 · ASCII码与类型转换
答案：C

题目：如果字符变量 _1 的值是字符 '1'，那么 (int)_1 的值是？（ ）

A. 1
B. -1
C. 49 ✓
D. +1 或者 -1

📝 解题过程

  • 在C++中，字符类型 char 实际上存储的是字符对应的ASCII码值（一个整数）
  • 字符 '1' 的ASCII码值是 49
  • (int)_1 将字符强制转换为整数，得到的就是它的ASCII码值 49
  • 如果要得到数字 1，需要用 _1 - '0'（即 49 - 48 = 1）
ASCII码 字符 '0' 的ASCII码是 48，'1' 是 49，'2' 是 50……依次类推。将数字字符转为对应整数的方法是减去 '0'（即减去48）。

单选题 · 位运算与异或交换
答案：B

题目：a, b是整型变量，各自有互不相同的初始值。下列程序实现了什么效果？（ ）

1  a = a ^ b;
2  b = a ^ b;
3  a = a ^ b;
A. a, b 的值从始至终都没有改变。
B. a, b 的值实现了互换。 ✓
C. a, b 的值互换了以后，又还回去了，相当于没有变化。
D. a, b 的值最后和原值不一样，没有任何意义。

📝 解题过程

这是经典的异或（XOR）交换算法，可以在不使用第三个变量的情况下交换两个整数的值。

推导过程（设初始值 a = A, b = B）：

  • 第1步：a = A ^ B（此时 a = A^B, b = B）
  • 第2步：b = (A^B) ^ B = A ^ (B^B) = A ^ 0 = A（此时 a = A^B, b = A）
  • 第3步：a = (A^B) ^ A = (A^A) ^ B = 0 ^ B = B（此时 a = B, b = A）

交换完成！

异或三性质 X ^ X = 0（相同为0），X ^ 0 = X（与0异或不变），满足交换律和结合律。

单选题 · 字符数组与字符串结束符
答案：C

题目：关于下列正确的程序段，说法正确的是（ ）

1  char str1[] = "Hello";
2  char str2[] = {'H','e','l','l','0'};
A. 字符数组 str1 和 str2 完全相同。
B. 多次执行输出 str1 和 str2 将输出不同的结果。
C. 字符数组 str1 和 str2 不相等。 ✓
D. 这两个赋值方式完全相同。

📝 解题过程

  • char str2[] = {'H','e','l','l','0'}; —— 注意最后一个字符是数字 '0'（ASCII码48），不是空字符 '\0'！数组长度恰好为 5
  • 两者长度不同、内容不同（str1有结束符，str2没有），所以它们不相等
易混淆点 用 "" 初始化字符数组会自动加 '\0'；用 {} 列表初始化则不会。注意区分数字 '0'（ASCII 48）和空字符 '\0'（ASCII 0）。

单选题 · 未定义行为
答案：A

题目：关于以下程序段，说法正确的是（ ）

1  int x = 10;
2  cout << (x++) + (++x) << endl;
A. C++11 标准中，这是未定义行为，不同的环境有可能出现不同的结果 ✓
B. 22
C. 21
D. 20

📝 解题过程

  • (x++) + (++x) 在同一个表达式中对一个变量进行了两次修改
  • 两次修改之间没有顺序点（sequence point）
  • C++ 标准规定，在两个顺序点之间多次修改同一变量属于未定义行为（Undefined Behavior）
  • 不同编译器可能产生不同结果，不可依赖此类代码
编程规范 在同一个表达式中，不要对一个变量同时使用多个 ++ 或 -- 操作。这属于未定义行为，应当避免。

单选题 · 补码计算
答案：D

题目：8 位二进制下，十进制数 -15 的补码是（ ）

A. 11110000
B. 10001111
C. 10010000
D. 11110001 ✓

📝 解题过程

计算 -15 的8位补码，分三步：

  • 第一步：写出 +15 的原码（8位）
    15 = 8+4+2+1 = 00001111₂
  • 第二步：求反码（按位取反）
    00001111 → 11110000
  • 第三步：反码加1得补码
    11110000 + 1 = 11110001
补码公式 补码 = 反码 + 1。8位补码范围：-128 ~ +127。最高位是符号位（1表示负数）。

A. 63
B. 65 ✓
C. 67

📝 解题过程

按位展开法，将三进制数 2102₃ 转换为十进制：

2102₃ = 2×3³ + 1×3² + 0×3¹ + 2×3⁰

= 2×27 + 1×9 + 0×3 + 2×1

= 54 + 9 + 0 + 2 = 65

A. 4
B. 5 ✓
C. 6

📝 解题过程

  • sizeof(s) = 数组 s 声明时的大小 = 10（char s[10]）

答案：D

题目：模拟 "字符串加密"：规则为 "每个字符 ASCII 码 + 3，若超过 z (122) 则从 a 重新开始"，以下代码中正确的条件判断是：（ ）

1  for (int i = 0; i < str.length(); i++) {
2      // 需补充条件：
3      _______________________
4      else {
5          str[i] += 3;
6      }
7  }
A. if (str[i] > 122) str[i] = str[i] + 3 - 26;
B. if (str[i] > 122) str[i] = str[i] - 26;
C. if (str[i] + 3 > 122) str[i] = str[i] - 26;

循环加密公式 正确做法：先判断加偏移后是否超范围，若超出则从 'a' 开始循环。公式：'a' + (原字符+偏移-'z') - 1。

答案：✓ 正确

题目：如果 a 为 int 类型的变量，且 a 的二进制最低位为 0，则表达式 ((a & 3 & 1) == 0) 的值为 true。

📝 解题过程

  • a 的二进制最低位为 0 → a 是偶数
  • a 最低位为 0，所以 a & 1 = 0（任何数与1做&，结果只看该数的最低位）
  • (a & 3 & 1) 中 & 从左到右结合，最终 & 1 时结果的最低位取决于 a 的最低位
  • a 最低位为0，所以 (a & 3 & 1) = 0
  • (0 == 0) = true ✓
位运算技巧 任何数与 1 做 & 运算，结果只取决于该数的最低位。最低位为0（偶数）→ 结果为0；最低位为1（奇数）→ 结果为1。

编程题 · 25分 · 二进制回文串
枚举法

📖 试题名称：二进制回文串

时间限制：1.0 s    内存限制：512.0 MB

题目描述

对于一个正整数，我们将其转换为不含前导零的二进制表示，如果这个二进制序列从左向右读与从右向左读完全相同，则称该数为二进制回文数。例如，9 的二进制表示为 1001，是二进制回文数；10 的二进制表示为 1010，不是二进制回文数。

你的任务是：给定一个正整数 n，计算在 1 到 n 的范围内二进制回文数的数量。

输入格式

输入一行，包含一个正整数 n。

输出格式

输出一行，包含一个数，表示在 1 到 n 的范围内二进制回文数的数量。

样例

输入样例：

1  15

输出样例：

1  6

样例解释

1 到 15 范围内：1(1)、3(11)、5(101)、7(111)、9(1001)、15(1111) 是二进制回文数，共 6 个。

📝 解题思路

核心思路：枚举 1~n 的每个数 → 转二进制 → 判断回文 → 统计个数。

  • 第1步：遍历 i 从 1 到 n
  • 第2步：将 i 转换为二进制（不断除以2取余数，存入数组）
  • 第3步：用双指针判断数组是否回文（a[j] 与 a[pos-1-j] 比较）
  • 第4步：统计回文数的个数并输出
核心方法 十进制转二进制：不断除以2，记录余数，倒序排列。回文判断：比较 a[i] 和 a[len-1-i] 是否全部相等。

参考程序

 1  #include <iostream>
 2
 3  using namespace std;
 4
 5  int main() {
 6      int n, a[50] = {0}, ans = 0;
 7      cin >> n;
 8      for(int i = 1; i <= n; i++) {
 9          int t = i, pos = 0;
10          while(t) {
11               a[pos++] = t % 2;
12               t /= 2;
13          }
14          bool ok = true;
15          for(int j = 0; j < pos; j++)
16               if(a[j] != a[pos - j - 1]) {
17                   ok = false;
18                   break;
19              }
20          ans += ok;
21      }
22      cout << ans;
23      return 0;
24  }

编程题 · 25分 · 凯撒密码
模运算

📖 试题名称：凯撒密码

时间限制：1.0 s    内存限制：512.0 MB

题目描述

凯撒密码是一种替换加密技术，明文中的所有字母都在字母表上向后（或向前）按照一个固定数目进行偏移后被替换成密文。例如，当偏移量是 3 的时候，所有的字母 A 将被替换成 D，B 被替换成 E，以此类推，X 被替换成 A，Y 被替换成 B，Z 被替换成 C。

现在给你一个已破解的凯撒密码明文与密文，与一个有相同偏移量的未破解凯撒密码密文，请你帮忙破解它。

输入格式

输入共三行：

  • 第一行包含一个字符串，表示已破解的凯撒密码明文
  • 第二行包含一个字符串，表示已破解的凯撒密码密文
  • 第三行包含一个字符串，表示待破解的凯撒密码密文

输出格式

输出一行，包含一个字符串，表示待破解的凯撒密码对应的明文。

样例

输入样例：

1  ABCDEFGVWXYZ
2  DEFGHIJYZABC
3  WKHTXLFNEURZQIRAMXPSVRYHUWKHODCBGRJ

输出样例：

1  THEQUICKBROWNFOXJUMPSOVERTHELAZYDOG

样例解释

通过已破解的密码得出偏移量为 'D' - 'A' = 3。对未破解部分进行逆向偏移：密文中的 W 对应明文中的 T（'W' - 3 = 'T'），以此类推。

📝 解题思路

核心思路：根据已知明文-密文对求偏移量 → 用偏移量逆向解密。

  • 第1步：计算偏移量 d = 明文字符 - 密文字符（如 'A' - 'D' = -3），调整到 0~25：d = (d % 26 + 26) % 26
  • 第2步：对每个密文字符，加偏移量得到明文字符：(密文[i] - 'A' + d) % 26 + 'A'
  • 第3步：输出解密后的字符串
凯撒解密公式 明文 = (密文 - 'A' + 偏移量) % 26 + 'A'。模运算 % 26 保证了字母的循环（Z之后回到A）。

参考程序

 1  #include <iostream>
 2  #include <cstring>
 3
 4  using namespace std;
 5
 6  int main() {
 7      string s1, s2, s3;
 8      cin >> s1 >> s2 >> s3;
 9      int d = s1[0] - s2[0];
10      d = (d % 26 + 26) % 26;
11      for(int i = 0; i < s3.length(); i++) {
12          int ch = (s3[i] - 'A' + d) % 26;
13          cout << (char)(ch + 'A');
14      }
15      return 0;
16  }
