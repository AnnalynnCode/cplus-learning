单选题 · 指针声明
答案：A

题目：在C++中，声明一个指向整型变量的指针的正确语法是（ ）。

A. int* ptr; ✓
B. *int ptr;
C. int ptr*;
D. ptr int;

📝 解题过程

  • C++ 中指针声明的语法是：类型* 变量名;
  • int* ptr; 声明了一个名为 ptr 的指针，它指向 int 类型的数据。
  • *int ptr; 语法错误，* 应该放在类型后面或变量名前面。
  • int ptr*; 语法错误。
  • ptr int; 语法错误。
  • 等价写法：int *ptr;（星号靠近变量名）也是正确的，但选项中没有。两者含义完全相同。
指针声明格式 类型* 变量名; 或 类型 *变量名; 或 类型 * 变量名; 都是合法的，含义相同。

单选题 · 二维数组参数
答案：D

题目：下面的函数接收一个 3 行 4 列的二维数组并输出其中元素，则横线上不能填写（ ）。

void printArray(________) {
    for (int i = 0; i < 3; ++i)
        for (int j = 0; j < 4; ++j)
            std::cout << arr[i][j] << " ";
}
A. int arr[3][4]
B. int arr[][4]
C. int (*arr)[4]
D. int** arr ✓

📝 解题过程

  • A 可以：int arr[3][4] 直接指定两个维度，合法。
  • B 可以：int arr[][4] 省略第一维（3），合法。
  • C 可以：int (*arr)[4] 是指向"4个int组成的数组"的指针，可以用 arr[i][j] 访问，合法。
  • D 不可以：int** arr 是指向指针的指针（二级指针）。用 arr[i][j] 访问时，编译器不知道每行有多少列，无法正确计算偏移。所以不能填写。
二级指针 vs 二维数组 int** 和二维数组在内存中的布局完全不同！int** 是指针数组，二维数组是连续内存块。int** 不能直接替代二维数组参数。

单选题 · 栈 vs 堆内存
答案：D

题目：在C++中，int arr[3][4] 和 int* arr = new int[12] 均可模拟一个 3 行 4 列的二维数组。关于这两种方式，下面说法错误的是（ ）。

A. int arr[3][4] 在栈上分配空间，适合数组较小的情况
B. int* arr = new int[12] 在堆上分配空间，数组较大时也适用
C. 这两种方式申请的内存空间都是连续的
D. 这两种方式申请的内存都能自动释放 ✓

📝 解题过程

  • A 正确：栈上的局部数组在离开作用域时自动释放，但栈空间有限（通常几MB），适合小数组。
  • B 正确：堆（heap）空间大得多，适合大数组。new 在堆上分配。
  • C 正确：两种方式分配的内存都是连续的。arr[3][4] 是连续48字节（12个int），new int[12] 也是连续48字节。
  • D 错误：用 new 分配的内存不会自动释放，必须用 delete[] 手动释放，否则会造成内存泄漏。
new/delete 配对原则 new 分配的内存必须用 delete 释放，new[] 必须用 delete[] 释放。堆内存不会自动回收（除非程序结束）。

单选题 · 函数声明顺序
答案：B

题目：关于以下 C++ 代码，说法正确的是（ ）。

int main() {
    greet();
    return 0;
}

void greet() {
    cout << "Hello!" << endl;
}
A. 正确编译并输出 Hello!
B. 编译错误：找不到函数 greet() ✓
C. 编译警告但可以运行
D. 链接错误

📝 解题过程

  • 在 C++ 中，函数必须在使用前被声明或定义。
  • 这里 greet() 的定义在 main() 之后，而且没有前置声明。
  • 当编译器处理到 main() 中的 greet() 时，它还"不认识"这个函数，会报编译错误。
  • 解决方法：要么把 greet() 定义放在 main() 前面，要么在 main() 前面加一句 void greet();（函数声明）。
编译 vs 链接错误 找不到函数声明是编译错误（编译器不认识这个函数名）。链接错误发生在编译通过后找不到函数的实现代码。

单选题 · 参数传递修改结构体
答案：C

题目：在C++中，如果希望通过函数修改传入的结构体对象的内容，应该使用哪种参数传递方式？

A. 值传递或引用传递
B. 值传递或指针传递
C. 引用传递或指针传递 ✓
D. 仅指针传递

📝 解题过程

  • 想要修改原对象，就不能用值传递（值传递只修改副本，不影响原对象）。
  • 引用传递：形参是实参的别名，修改形参就是修改原对象。例如 void modify(Person &p)
  • 指针传递：传递对象的地址，通过解引用 *ptr 或箭头 ptr-> 修改原对象。
  • 两种方式都可以实现修改原对象的目的。
修改原对象的方法 引用传递：void f(Person &p) { p.age = 20; }
指针传递：void f(Person* p) { p->age = 20; }

单选题 · 形参与实参
答案：B

题目：以下哪个选项正确描述了C++中形参和实参的区别？

A. 形参是函数调用时传递给函数的具体值，实参是函数定义中声明的变量。
B. 形参是函数定义中声明的变量，实参是函数调用时传递给函数的具体值。 ✓
C. 形参和实参在函数调用时是完全相同的。
D. 形参只在函数内部可见，实参在函数外部可见。

📝 解题过程

  • 形参（形式参数）：函数定义时在括号中声明的变量，如 int add(int x, int y) 中的 x 和 y。
  • 实参（实际参数）：调用函数时传入的具体值，如 add(3, 5) 中的 3 和 5。
  • A 说反了（把形参和实参的定义搞反了）。
  • C 错误：形参和实参是不同变量（值传递时形参是实参的副本）。
  • D 对了一半但不完整：形参确实只在函数内部可见，但"实参在函数外部可见"只是它本身作用域决定的，不是两者的核心区别。
  • B 是对形参和实参最准确的描述。
简单记忆 形参 = 形式上的参数（定义函数时写出来的）
实参 = 实际传入的参数（调用函数时传进去的）

单选题 · 全局变量与作用域
答案：C

题目：运行如下代码会输出（ ）。

int value = 100;

void print1() {
    int value = 50;
    cout << value << " ";
    cout << ::value << " ";
}

void print2() {
    cout << value << " ";
}

print1();
print2();
A. 100 100 100
B. 50 50 50
C. 50 100 100 ✓
D. 50 50 100

📝 解题过程

  • 全局变量：value = 100
  • print1() 中：
    • 定义了局部变量 value = 50，遮蔽了全局变量。
    • cout << value → 输出局部变量的值 50
    • cout << ::value → :: 是全局作用域解析运算符，用来访问被遮蔽的全局变量 → 输出 100
  • print2() 中：
    • 没有局部变量 value，直接使用全局变量 → 输出 100
  • 最终输出：50 100 100
:: 作用域运算符 ::变量名 可以访问被局部变量遮蔽的全局变量。这在 C++ 中是解决变量名冲突的重要工具。

单选题 · 排序算法识别
答案：B

题目：小杨在整理一副扑克牌的所有红心扑克牌，使其从小到大排列。他的做法是：最开始抓到第1张扑克牌被认为已经排好序；然后抓第2张扑克牌，将其插入至有序部分的正确位置；不断循环步骤，每次将新抓到扑克牌插入至有序部分，直至抓完所有扑克牌，这样抓牌结束时就完成了扑克牌的排序。小杨这种整理扑克牌的方式与（ ）排序的方式最接近。

A. 冒泡排序
B. 插入排序 ✓
C. 选择排序
D. 直接排序

📝 解题过程

  • 题目描述的是典型的插入排序思想：
  • ① 一开始手中只有1张牌，天然有序。
  • ② 每次拿一张新牌，"插入"到已有序牌的正确位置。
  • ③ 重复直到所有牌都在手中排好序。
  • 这就像打扑克时整理手牌：每次摸一张牌，把它插到合适的位置。
  • 冒泡排序是不断交换相邻元素，选择排序是每次选最小的放到前面，都和"插入"的思路不同。
插入排序的比喻 就像打牌时整理手牌：每次摸一张牌，在已有的有序牌中找到它应该放的位置，插进去。这就是插入排序。

单选题 · 插入排序适用场景
答案：C

题目：以下哪种情况是使用插入排序的合适场景？

A. 数据量非常大，且乱序严重
B. 希望获得稳定排序，但不要求实时性
C. 数据几乎有序，只需少量调整 ✓
D. 想在交换次数最少的前提下排好大数组

📝 解题过程

  • 插入排序的特点：
  • 最好情况（已有序）：只比较 n-1 次，不需要移动，O(n)——非常快。
  • 数据"几乎有序"时：插入排序只需很少的比较和移动，效率极高。
  • 最坏情况（完全逆序）：O(n²)，效率低。
  • A 不合适：数据量大且乱序，O(n²) 会很慢，应该用快速排序或归并排序。
  • B 不合适：应该用归并排序（稳定且 O(n log n)）。
  • C 最合适：插入排序在"几乎有序"的数据上表现最佳。
  • D 不合适：选择排序比插入排序交换次数少（每轮最多1次交换）。
插入排序的最佳舞台 当数据基本有序时，插入排序接近 O(n)，是所有排序算法中最好的选择之一。

单选题 · 递推算法思想
答案：B

题目：以下关于递推算法基本思想的描述，正确的是（ ）。

A. 递推算法通过将问题分解为相互独立的子问题来解决。
B. 递推算法从已知的基础情况出发，通过某种关系逐步推导出更大规模问题的解。 ✓
C. 递推算法通常用于穷举所有可能的解决方案。
D. 递推算法适用于在每一步做出局部最优选择以达到全局最优。

📝 解题过程

  • A 错误："分解为相互独立的子问题"描述的是分治算法（如归并排序），不是递推的特征。
  • B 正确：递推的核心是：知道初始值（如 f(1)=1），利用递推关系（如 f(n)=f(n-1)+n），从小到大逐步推导出目标值。
  • C 错误：穷举所有方案是枚举/暴力搜索，不是递推。
  • D 错误："每一步局部最优达到全局最优"是贪心算法的特征。
四种算法思想对比 递推：从小到大推导  |  分治：分解为独立子问题  |  贪心：每步选局部最优  |  枚举：穷举所有可能

单选题 · 时间复杂度
答案：B

题目：给定如下算法，其时间复杂度为（ ）。

bool f(int arr[], int n, int target) {
    for (int i = 0; i < n; i++) {
        int sum = 0;
        for (int j = 0; j < n; j++) {
            if (i & (1 << j)) {
                sum += arr[j];
            }
        }
        if (sum == target) return true;
    }
    return false;
}
A. O(n)
B. O(n²) ✓
C. O(n³)
D. O(2ⁿ)

📝 解题过程

  • 注意：外层循环是 for (int i = 0; i < n; i++)，不是 i < (1<<n)！这与第3题不同。
  • 外层循环：执行 n 次。
  • 内层循环：for (int j = 0; j < n; j++)，执行 n 次。
  • 总执行次数 ≈ n × n = n²
  • 时间复杂度为 O(n²)。
与3月真题的对比 这道题的外层循环是 i < n（n次），而3月真题中是 i < (1<<n)（2ⁿ次）。粗心看错就全错了！仔细审题很重要。

单选题 · 递归时间复杂度
答案：D

题目：下述斐波那契数列计算的时间复杂度是（ ）。

int fibonacci(int n) {
    if (n == 0) return 0;
    if (n == 1) return 1;
    return fibonacci(n - 1) + fibonacci(n - 2);
}
A. O(n)
B. O(n²)
C. O(n log n)
D. O(2ⁿ) ✓

📝 解题过程

  • 这是递归实现斐波那契（注意：这是递归，不是递推！递归是从大到小，递推是从小到大）。
  • 每次调用 fibonacci(n) 会分裂成 fibonacci(n-1) 和 fibonacci(n-2) 两个调用。
  • 这种二叉树状的递归会产生大量重复计算。
  • 调用次数 ≈ 2ⁿ 级别（准确来说是约 1.618ⁿ，即黄金比例的 n 次方）。
  • 时间复杂度：O(2ⁿ)，随着 n 增大会指数级爆炸。
  • 例如计算 fib(50) 需要上万亿次运算！
递归 vs 递推 计算斐波那契 递归（从大到小）：O(2ⁿ) — 非常慢，大量重复计算
递推（从小到大）：O(n) — 非常快，每个值只算一次

ifstream in("data.txt");

单选题 · 冒泡排序优化
答案：B

题目：为了提高冒泡排序的效率，如果某轮"冒泡"中没有执行任何交换操作，说明数组已经完成排序，可直接返回结果，则两条横线上分别应该填写（ ）。

void bubbleSortWithFlag(vector<int> &nums) {
    for (int i = nums.size() - 1; i > 0; i--) {
        bool flag;
        ________________    // 在此处填入代码

            for (int j = 0; j < i; j++) {
                if (nums[j] > nums[j + 1]) {
                    swap(nums[j], nums[j + 1]);
                    ___________________________             // 在此处填入代码
                }
            }

                break;
        }
}
A. flag = false; flag = false;
B. flag = false; flag = true; ✓
C. flag = true; flag = false;
D. flag = true; flag = true;

📝 解题过程

  • 这是带标志位的冒泡排序优化：
  • flag 的作用是记录本轮是否发生了交换。
  • 第一处横线（每轮循环开始前）：需要把 flag 重置为 false，假设本轮没有交换。

判断题 · 值传递
答案：✗ 错误

题目：下面C++代码的输出是 15。

void foo(int x) {
    x += 5;
}
int main() {
    int a = 10;
    foo(a);

}

📝 解析

值传递要点 函数内部对值传递参数的修改不会影响调用处的原变量。要想修改原变量，需要用引用传递或指针传递。

判断题 · 递推计算阶乘

题目：以下程序中使用了递推方式计算阶乘（n!），计算结果正确。

int factorial(int n) {

    }
    return res;
}

📝 解析

正确写法应该是 for (int i = 1; i <= n; ++i) 或 for (int i = 2; i <= n; ++i)。

正确版本 for (int i = 2; i <= n; ++i) res *= i; 或 for (int i = 1; i <= n; ++i) res *= i;

判断题 · 选择排序比较次数
答案：✓ 正确

题目：无论初始数组是否有序，选择排序都执行 O(n²) 次比较。

📝 解析

正确。选择排序的比较次数是固定的：第一轮比较 n-1 次，第二轮比较 n-2 次……总共 n(n-1)/2 次，恒为 O(n²)。无论数组是已经有序、完全逆序还是随机排列，比较次数都一样。

选择排序的特点 比较次数固定 O(n²)，但交换次数很少（每轮最多1次）。这与冒泡排序不同——冒泡排序加 flag 优化后在有序情况下只需 O(n) 比较。

判断题 · 选择排序代码识别
答案：✓ 正确

题目：以下C++代码，尝试对有 n 个整数的数组 arr 进行排序。这个代码实现了选择排序算法。

for (int i = 0; i < n - 1; ++i) {
    int minIndex = i;
    for (int j = i + 1; j < n; ++j) {
        if (arr[j] < arr[minIndex])
            minIndex = j;
    }
    if (minIndex != i)
        swap(arr[i], arr[minIndex]);
}

📝 解析

正确。这是标准的选择排序实现：

  • 外层循环 i：确定第 i 个位置应该放谁。
  • 内层循环：在 i 之后找最小值的索引 minIndex。
  • 找到后把最小值和 arr[i] 交换。
  • 这正是选择排序的核心思想：每次选择最小的放到前面。

题目：画布裁剪

题目描述：小 A 在高为 n 宽为 m 的矩形画布上绘制了一幅画。由于画布边缘留白太多，小 A 想适当地裁剪画布，只保留画的主体。具体来说，画布可以视为 n 行 m 列的字符矩阵，小 A 只保留画布中由第 x1 行到第 x2 行、第 y1 列到第 y2 列构成的子矩阵。你能帮他完成画布的裁剪吗？

输入格式：

  • 第一行，两个正整数 n, m，分别表示画布的行数与列数。
  • 第二行，四个正整数 x1, x2, y1, y2，表示保留的行列边界。
  • 接下来 n 行，每行一个长度为 m 的字符串，表示画布内容。

输出格式：输出共 (x2-x1+1) 行，每行一个长度为 (y2-y1+1) 的字符串，表示裁剪后的画布。

输入样例1：

3 5
2 2 2 4
.....
.>_<.
.....

输出样例1：

>_<

输入样例2：

5 5
1 2 3 4
AbCdE
fGhIk
LmNoP
qRsTu
VwXyZ

输出样例2：

Cd
hI

📝 详细解析

核心思路：

  1. 这是一个简单的子矩阵截取问题。
  2. 读入完整画布后，只需要输出第 x1~x2 行、第 y1~y2 列的字符。
  3. 注意行列索引：题目中行列号从 1 开始，需要对应到数组索引（从0或1开始取决于实现）。

样例1执行过程：

  • 画布 3×5，保留 x1=2, x2=2, y1=2, y2=4
  • 即只保留第2行、第2~4列
  • 第2行：.>_<.，取第2~4列 → >_<

样例2执行过程：

  • 画布 5×5，保留 x1=1, x2=2, y1=3, y2=4
  • 第1行：AbCdE，取第3~4列 → Cd
  • 第2行：fGhIk，取第3~4列 → hI

时间复杂度：O(n×m)，实际只需输出子矩阵部分。

参考代码：

#include <cstdio>
using namespace std;

const int N = 105;
int n, m;
char s[N][N];
int x1, x2, y1, y2;

int main() {
    scanf("%d%d", &n, &m);
    scanf("%d%d%d%d", &x1, &x2, &y1, &y2);
    for (int i = 1; i <= n; i++)
        scanf("%s", s[i] + 1);
    for (int i = x1; i <= x2; i++) {
        s[i][y2 + 1] = 0;             // 在截取结束位置加字符串终止符
        printf("%s\n", s[i] + y1);    // 从 y1 位置开始打印
    }
    return 0;
}
核心技巧 s[i][y2+1] = 0 在截取末尾放置字符串终止符，然后 s[i] + y1 从截取起始位置开始打印。这是一个巧妙的技巧，避免了逐字符输出的麻烦。

编程题 · 排序/逆序对
25分

题目：排序

题目描述：体育课上有 n 名同学排成一队，从前往后数第 i 位同学的身高为 hᵢ，体重为 wᵢ。目前排成的队伍看起来参差不齐，老师希望同学们能按照身高从高到低的顺序排队，如果身高相同则按照体重从重到轻排序。在调整队伍时，每次只能交换相邻两位同学的位置。老师想知道，最少需要多少次交换操作，才能将队伍调整成目标顺序。

输入格式：

  • 第一行，一个正整数 n，表示队伍人数。
  • 接下来 n 行，每行两个正整数 hᵢ 和 wᵢ，分别表示第 i 位同学的身高和体重。

输出格式：输出一行，一个整数，表示最少需要的交换次数。

输入样例1：

5
1 60
3 70
2 80
4 55
4 50

输出样例1：8

输入样例2：

5
4 0
4 0
2 0
3 0
1 0

输出样例2：1

📝 详细解析

核心思路：

  1. 这个问题本质上是在求逆序对的数量。每次交换相邻元素最多消除1个逆序对，最少需要"逆序对数"次相邻交换。
  2. 排序规则：身高从高到低（降序），身高相同按体重从重到轻（降序）。注意是降序！
  3. 算法步骤：
    • 目标顺序：将数组按 (身高, 体重) 降序排列。
    • 统计满足 i < j 且 a[i] < a[j]（按照排序规则）的数对数量——这就是需要交换的次数。
  4. 参考程序使用的方法：对每一对 (i, j)，如果 a[i] < a[j]（即前面的同学按排序规则应该在后面的同学之后），就是一个逆序对。

样例2执行过程：

  • 输入：(4,0), (4,0), (2,0), (3,0), (1,0)
  • 目标顺序（降序）：(4,0), (4,0), (3,0), (2,0), (1,0)
  • 当前顺序和目标对比：第3位(2,0)和第4位(3,0)需要交换 → 1次相邻交换即可
  • 输出：1

时间复杂度：O(n²)，对于给定的数据范围可以通过。更优的解法可以用归并排序求逆序对（O(n log n)）或树状数组。

参考代码：

#include <cstdio>
#include <algorithm>
#include <vector>
#include <iostream>
using namespace std;

int main() {
    int n, ans = 0;
    scanf("%d", &n);
    vector<pair<int,int>> a(n);

    for (int i = 0; i < n; i++)
        scanf("%d%d", &a[i].first, &a[i].second);

    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++)
            if (a[i] < a[j])    // pair 默认先比 first，后比 second
                ans++;

    cout << ans << '\n';
    return 0;
}
核心知识点 逆序对：相邻交换排序的最少操作次数 = 逆序对数  |  pair 比较规则：默认先比 first，first 相同比 second  |  注意排序方向：身高高的在前（降序），所以 a[i] < a[j] 时说明 i 和 j 顺序不对
