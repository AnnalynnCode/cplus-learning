单选题 · 原码与补码
答案：B

题目：下列二进制表示的十进制数值分别是（ ）

[10000011]原 = (   )
[10000011]补 = (   )
A. -125，-3
B. -3, -125 ✓
C. -3，-3
D. -125，-125

📝 解题过程

  • 原码 [10000011]：最高位1表示负数，数值部分 0000011 = 3，所以是 -3
  • 补码 [10000011]：最高位1表示负数。先减1得 10000010，再取反（符号位不动）得 11111101 = 125，所以是 -125
  • 验证：-125 的补码 = 125 取反+1 = 01111100+1 = 01111101，加上符号位 = 10000011 ✓
原码 vs 补码 同一个二进制串，在不同编码方式下代表不同的值。原码简单直观，补码适合运算。

单选题 · 编码概念
答案：D

题目：关于计算机中的编码，下列说法中错误的是（ ）

A. 对于无符号数，原码就是真值
B. 正数的反码是其本身
C. 负数的反码和补码是不一样的
D. 负数的反码，在其原码的基础上，各个位取反 ✓

📝 解题过程

  • A 正确：无符号数没有符号位，原码（二进制本身）就是它的真值
  • B 正确：正数的反码就是它本身（符号位为0不变）
  • C 正确：负数的反码和补码确实不同（补码 = 反码 + 1）
  • D 错误：负数的反码是"符号位不变，数值位按位取反"，不是各个位都取反！如果符号位也取反，负数就变正数了
反码规则 正数反码 = 本身；负数反码 = 符号位不变，其余位按位取反。符号位始终不变！

单选题 · 补码右移
答案：B

题目：补码1111 1101进行运算1111 1101>>1以后得到的结果是（ ）

A. 1111 1100
B. -2 ✓
C. 1111 1101
D. 1111 1010

📝 解题过程

  • 1111 1101 是8位补码，先看它表示什么数：
  • 符号位=1（负数）。减1：1111 1100。取反：0000 0011 = 3。所以值是 -3
  • >>1 算术右移1位：最高位（符号位）保持不变，其余位右移，最低位丢弃
  • 1111 1101 >> 1 = 1111 1110
  • 1111 1110 是补码：减1→1111 1101，取反→0000 0010=2，值=-2
  • 数学上：-3 ÷ 2 = -1.5，向负无穷取整 = -2
算术右移 补码右移 n 位 ≈ 除以 2ⁿ，向下取整。符号位保持不变（算术右移）。

单选题 · 位运算分析
答案：A

题目：a|10（a与10都是10进制，且二进制表示最高位为1）运算的结果是（ ）。

A. 使a的二进制表示从右往左的第二位为1 ✓
B. 使a的二进制表示从右往左的第一位为0
C. 使a的二进制表示从右往左第二位为0
D. 使a的二进制表示最高位为0

📝 解题过程

  • 10的二进制：1010

  • 10 = 1010，所以在第1位和第3位（从右往左数，从0开始）是1：
  • a | 1010 会使 a 的第1位和第3位强制变成1，其他位保持不变
  • "从右往左的第二位"即第1位（从0计数），确实会变成1 ✓
  • B/C：第0位不受影响（10的第0位是0）。D：最高位不受影响（除非a本身最高位是1）

判断题 · 补码原理
答案：✓ 正确

题目：为了简化计算机基本运算电路，使加减法都只需要通过加法电路实现，也就是让减去一个正数或加上一个负数这样的运算可以用加上一个正数来代替。于是改变负数存储的形式，存储成一种可以直接当成正数来相加的形式，这种形式就是补码。

📝 解析

正确。这段描述精准概括了补码的设计初衷。A - B 在补码下变成 A + (-B的补码)，而 -B的补码可以当作一个正数来处理，电路只需要做加法即可。

判断题 · 原码加法
答案：✓ 正确

题目：使用原码进行的计算，2+(-1)的结果是 -3。

📝 解题过程

  • 原码：+2 = 0000 0010，-1 = 1000 0001
  • 直接相加：0000 0010 + 1000 0001 = 1000 0011
  • 在原码中，1000 0011 = -3
  • 正确结果应该是 1，但原码直接相加得到 -3。这恰好说明了原码不适合直接做加减法
这就是为什么计算机不直接用原码做运算，而要引入补码。

判断题 · 进制转换方向
答案：✗ 错误

📝 解题过程

题目：数字替换

题目描述：小杨有一个包含 n 个数字的序列 A，他想将其中大于 k 的数字都替换为序列的最大值，将其中小于 k 的数字都替换为序列的最小值，等于 k 的数字不变。请你帮他计算出替换后的序列。

输入格式：

  • 第一行包含两个正整数 n, k
  • 第二行包含 n 个数字，代表序列 A

输出格式：输出 n 个整数，代表替换后的结果。

样例：

输入：
5 0
-2 -1 0 1 2

输出：
-2 -2 0 2 2

📝 详细解析

核心思路：

  1. 先遍历一遍找到最大值和最小值
  2. 再遍历一遍：大于k的替换为最大值，小于k的替换为最小值

样例执行（k=0）：

  • 序列 [-2, -1, 0, 1, 2]：最大值=2，最小值=-2
  • -2 < 0 → 替换为 -2（和原值一样）；-1 < 0 → -2；0 = k → 不变
  • 1 > 0 → 2；2 > 0 → 2（和原值一样）
  • 结果：-2, -2, 0, 2, 2

参考代码：

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int a[100010];

int main() {
    int n, k;
    cin >> n >> k;
    for (int i = 1; i <= n; i++)
        cin >> a[i];

    int max_v = a[1], min_v = a[1];
    for (int i = 1; i <= n; i++) {
        max_v = max(max_v, a[i]);
        min_v = min(min_v, a[i]);
    }

    for (int i = 1; i <= n; i++) {
        if (a[i] > k)
            a[i] = max_v;
        else if (a[i] < k)
            a[i] = min_v;
        cout << a[i] << (i == n ? "\n" : " ");
    }
    return 0;
}
知识点 两次遍历：先找极值，再替换。注意处理空格和换行的输出格式。

题目：打印数字

题目描述：小杨为数字 0, 1, 2 和 3 设计了一款表示形式，每个数字占用了 5×5 的网格：

..... ****. ..... .....
.***. ****. ****. ****.
.***. ****. ..... .....
.***. ****. .**** ****.
..... ****. ..... .....
  (0)   (1)   (2)   (3)

小杨想请你将给定的数字 n 转换为对应的表示形式。

输入：一个由数字0,1,2,3组成的字符串。
输出：5行，每行是每个数字对应行的拼接。

样例：

输入：12230
输出：
****.....................
****.****.****.****..***.
****.................***.
****..****.********..***.
****.....................

📝 详细解析

核心思路：

  1. 把每个数字的5行图案预定义好
  2. 逐行输出：对于第row行，依次拼接每个数字在该行的图案

样例分析（输入"12230"）：

  • 第0行：1(****.) + 2(****.) + 2(****.) + 3(****.) + 0(.....) = "****.****.****.****....." → 但输出是"****....................."？让我重新检查...
  • 实际上输入是"12230"，数字图案逐行拼接。每行按顺序拼接各数字的对应行即可

参考代码：

#include <iostream>
#include <string>
using namespace std;

int main() {
    string n;
    cin >> n;

    for (int row = 0; row < 5; row++) {
        string line = "";
        for (char digit : n) {
            if (digit == '0') {
                line += (row == 0 || row == 4) ? "....." : ".***.";
            } else if (digit == '1') {
                line += "****.";
            } else if (digit == '2') {
                line += (row == 0 || row == 2 || row == 4) ? "....."
                     : (row == 1) ? "****." : ".****";
            } else if (digit == '3') {
                line += (row == 0 || row == 2 || row == 4) ? "....." : "****.";
            }
        }
        cout << line << endl;
    }
    return 0;
}
核心知识点 逐行输出字符画的技巧：外层循环行号，内层循环每个字符，拼接各字符在该行的图案。
