# cplus-learning

C++ 编程学习与算法练习仓库，收录日常练习中完成的各类编程题目。

## 项目结构

```
cplus-learning/
├── C++/                    # C++ 练习题（约 440+ 道）
│   ├── GESP集训专项/       # GESP 等级考试集训题
│   └── 中科杯/              # 中科杯竞赛题目
└── algorithms/             # 算法专项练习
```

## 内容覆盖

- **基础语法**：输入输出、变量、数据类型、运算符
- **控制结构**：if 分支、for/while 循环、switch 选择
- **数组**：一维/二维数组、数组遍历、查找与统计
- **字符串**：C 风格字符串函数（strcpy/strcat/strcmp 等）、string 类
- **函数与递归**：自定义函数、递归调用
- **排序算法**：冒泡排序、选择排序、sort 函数应用
- **数学问题**：质数/素数、最大公约数、阶乘、质因子分解
- **算法入门**：贪心、枚举、模拟

## 题目来源

- 洛谷（Luogu）在线评测平台
- GESP（CCF 编程能力等级认证）
- NOIP（全国青少年信息学奥林匹克联赛）
- USACO（美国计算机奥林匹克竞赛）
- 其他信息学竞赛与 OJ 平台
