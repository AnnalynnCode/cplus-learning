# 4048 - 做题 (GESP2403四级)

- **题目来源**: [一本通 4048](http://ybt.ssoier.cn:8088/problem_show.php?pid=4048)
- **时间限制**: 1000ms | **内存限制**: 128MB

## 题目简述

第 $k$ 天需要完成 $k$ 道题。有 $n$ 套题单，每套有 $a_i$ 道题，每套只能用一次，每天只能用一套。求最多能坚持的天数。

## 解题思路

**贪心 + 排序**。将题单按题目数量从小到大排序，依次尝试匹配递增的天数需求。

- 第 $k$ 天需要 $k$ 道题，需求单调递增
- 小的题单匹配小的需求，大的题单留给后面的大需求，不会更差
- 若当前题单 $a_i < day$（连今天都不够），之后需求更大，更不可能用上，直接跳过

## 核心算法

```
1. 读入 n 和数组 a[0..n-1]
2. 对 a 升序排序
3. day = 1
4. for i in 0..n-1:
       if a[i] >= day:
           day = day + 1
5. 输出 day - 1
```

## 复杂度分析

| 项目 | 复杂度 |
|------|--------|
| 排序 | O(n log n) |
| 贪心遍历 | O(n) |
| 空间 | O(n)（存储数组） |

$n \le 10^6$，O(n log n) 可通过 1000ms 时限。

## 代码关键点

- 不能用 `vector`，使用 `new[]/delete[]` 动态分配数组
- `sort(a, a + n)` 对指针范围的数组排序
- `day` 初始为 1，`day - 1` 即为完成的最后一天
